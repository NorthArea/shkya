# Город Н

Демо-квест «За хлебом» на Godot в трёхмерном зимнем городе Н. (прототип — Новосибирск). Персонажи переходят в настоящее 3D с сохранением прежнего облика в манере Евы Морозовой из ШКЯ; новые переосмысленные модели отвергнуты владельцем 01.11 (см. DECISIONS). Принятые police/guard сохраняются. *The Simpsons: Hit & Run* — основной референс игрового мира и механик; художественный переход сохраняет существующий геймплей.

2. [docs/new_concept.md](docs/new_concept.md) — художественный переход к самостоятельной IP; уточнения владельца о сохранении police/guard и приоритете Hit & Run — в DECISIONS.
3. [docs/extension/](docs/extension/README.md) — канон расширения «Ничего необычного» (6 файлов, без правок).
4. [docs/extension/HIDE_SPOTS.md](docs/extension/HIDE_SPOTS.md) — ТЗ укрытий у киоска (правится только по решению владельца).
5. [docs/DEMO.md](docs/DEMO.md) — ТЗ демо 1.0 от 27.10.2026, без правок.
6. Концепты [docs/art/](docs/art/README.md): 01–10 и e01–e05 (PNG не изменять); облик — [CHARACTERS.md](docs/art/CHARACTERS.md), [CITY.md](docs/art/CITY.md).
7. [docs/SHKYA_NOVOSIBIRSK_AGENT_REFERENCES.md](docs/SHKYA_NOVOSIBIRSK_AGENT_REFERENCES.md) — единственный набор внешних референсов, без правок.

Значения констант — только в коде. Контракты кода C1–C11 — [docs/workflow/README.md](docs/workflow/README.md). Карта документов — [docs/README.md](docs/README.md).

## Стек и запуск

Godot 4.7.2, GDScript, Forward+, 1920×1080. `make run` — игра, `make test` и `make test-headless` — проверки без окна; графические наборы явно пропускаются. `make test-native` — только по отдельному явному разрешению владельца (список — Makefile). Локальная Godot.app — в `tools/local/` вне Git. Целевая платформа — этот Mac.

## Процесс

- Исходные просьбы владельца сохранены в [docs/requests/OWNER_MESSAGES.md](docs/requests/OWNER_MESSAGES.md), данные — в `docs/requests/owner_messages.json`. После перезапуска сверять связанные поручения с backlog; новые содержательные сообщения добавлять дословно в архив. Архив не заменяет DECISIONS и не содержит живых статусов.
- Очередь, зависимости и единственный живой статус — [docs/workflow/backlog.md](docs/workflow/backlog.md); правила и контракты — [docs/workflow/README.md](docs/workflow/README.md); карточки открытых задач — `docs/workflow/tasks/` (закрытые удаляются). Не заводить дубли канона, отдельные progress и отчёты приёмки.
- Логи проверок — `builds/checks/<ID>/`, кадры — `builds/screenshots/<ID>/`; `builds/` вне Git. Съёмщики кадров — `tools/capture/`.
- Технический PASS не заменяет ручной проход: проверка каркаса — не готовность миссии.
- Обычные автоматические проверки запускать без окна (`make test-headless` или адресно с `--headless`), чтобы не мешать владельцу работать на ноутбуке. Все проверки выполнять в фоне без видимых окон, фокуса и слышимого звука. Если рендер/кадры/реальный звук/FPS требуют видимого окна, не запускать без отдельного явного разрешения владельца; одного предупреждения недостаточно. Пропуски графических проверок явно указывать, не считать их PASS. Служебные скрипты запускать через `tools/run.command` или `tools/godot.sh`: общий launcher принудительно включает headless/Dummy. Прямой вызов Godot.app для обхода защиты запрещён. `GODOT_VISIBLE_CHECKS=1` разрешён только для явно запрошенной владельцем видимой проверки; не сохранять его в окружении сессии. `make run` по просьбе владельца открывает игру как обычно.
- [Карта арены](docs/maps/arena.png) и её SVG генерируются из данных игры: `make map`. При изменении геометрии, проходов, маршрутов или ориентиров обновляй карту перед коммитом; `make run`, `make editor`, `make test`, `make capture` и `make fps` обновляют её автоматически. Координаты править только в коде. На карте и в сообщениях владельцу использовать вывески и понятные ориентиры, служебные ID оставлять для кода.

## Режим работы

- Брать задачи из backlog по критическому пути и работать без остановок до блокера: решение владельца, необратимое или внешнее действие, запрет среды. На запрос отчёта — короткий отчёт и продолжение в том же ходе.
- Независимые задачи — параллельно силами субагентов, проверяя свободную память перед запуском.
- Законченную проверенную часть — атомарным коммитом с ID задачи. Пуш — только по отдельному поручению.
