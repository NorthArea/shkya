# ШКЯ: Ничего необычного — расширение демо «За хлебом»

**Сеттинг:** вымышленный Город Н, зимний, серый, грязный, с жёлтыми фонарями. **Это не Новосибирск**, хотя архитектура вдохновлена им.

**Назначение пакета:** расширить уже работающую часть «доехать до киоска → поговорить с продавщицей → купить хлеб», добавив городское патрулирование, угрозу принудительной «бесплатной поездки» и комические ситуации. Никакого нового сюжетного квеста.

## Состав
- `MISSION_EXTENSION.md` — сценарий и правила расширенной миссии.
- `STEALTH_DESIGN.md` — минимальная стелс-система, поведение NPC и транспорт.
- `DIALOGUES_AND_JOKES.md` — оригинальные реплики, ситуации, вывески, звуковые гэги.
- `GODOT_IMPLEMENTATION.md` — техническая структура Godot и задачи агента.
- `ACCEPTANCE_TESTS.md` — проверяемые требования и тест-кейсы.

Все диалоги оригинальные, написаны как черновики для согласования с правообладателем ШКЯ, не цитаты из мультфильмов и не попытка выдать их за слова Евы Морозовой.

## Главный принцип
Самый смешной персонаж здесь — система, которая совершенно серьёзно утверждает, что ничего необычного не происходит. Герои говорят коротко, канцелярит сталкивается с буквальным здравым смыслом. Илюша хочет **только хлеб**.

## Ограничения
- Играть только за Илюшу; Бабка остаётся квестодателем.
- Дружинника **нет**. Игровые роли: полицейский, сотрудник условного учётного ведомства («военком» на уровне авторского задания), росгвардеец; трое не должны становиться тремя полноценными типами боевого AI.
- Никакого насилия, оружия, перестрелок, физической борьбы, тяжёлых сцен задержания.
- Гротескный автобус не требует физики полноценного дорожного потока; движется по маршруту или играет постановочную сцену.
- Хлеб находится в инвентаре, в руках предмет не отображается.
- Никаких артов, моделей, текстур или фотографий в этом архиве.
