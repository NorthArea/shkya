# Укрытия у киоска: коробка, сугроб, бочка — ТЗ для EXT-02

**Статус:** второй канон, адаптация под проект (решение владельца 28.10.2026). Исходник — внешнее ТЗ «ШКЯ: Ничего необычного — расширение миссии „За хлебом“: пародийный стелс»; переписан под реальный код и удалён. Общие места исходника (обзор Godot API, протокол агента, предложенная структура сцены) заменены ссылками на действующие контракты проекта. Числа баланса — начальные значения для плейтестов, не требования.
**Приоритет среди канонов:** `docs/DEMO.md` → `docs/extension/` (README, MISSION_EXTENSION, STEALTH_DESIGN, GODOT_IMPLEMENTATION, DIALOGUES_AND_JOKES, ACCEPTANCE_TESTS) → этот документ. Где этот документ расходится с ними — действуют они; расхождения перечислены в разделе 12.

## 1. Цель и готовность

К стелс-участку EXT-01 (парковка → киоск, полицейский и автобус ГСУМ) добавить три укрытия, каждым из которых участок проходится самостоятельно:

1. **Коробка из-под батонов** — надеть, стоять незаметно, медленно идти заметно.
2. **Сугроб-укрытие** — зарыться и переждать разворот патруля.
3. **Бочка** — залезть и катиться быстрее коробки, но на виду.

Плюс **коэффициент заметности** в сенсоре: сегодня `DetectionSensor.visibility()` отдаёт 0 или 1, нужен 0…1 с учётом укрытия и дистанции.

**Готово, когда:** прежний квест (`!` → машина → киоск → покупка → машина → `?` → сдача) проходится без изменений; участок между `Layout.STEALTH_CHECKPOINT` и окном продавщицы проходится каждым из трёх укрытий; обнаружение ведёт на существующий экран «ВАШ МАРШРУТ УТОЧНЁН» и респавн без порчи `MissionDirector` и `has_bread`; `make test` — 0 failures, новый набор `HIDE` в Makefile.

## 2. Границы

**Входит:** один участок (он уже есть — EXT-01), по одному экземпляру каждого укрытия, коэффициент заметности, подсказки `E`, 5 коротких гэгов субтитрами, чекпоинт — существующий, регрессионные тесты.

**Не входит:** правки `MissionDirector`, `QuestFlow`, покупки, инвентаря, езды, сдачи; новые этапы квеста; второй наблюдатель сверх EXT-01; физическая бочка на `RigidBody3D`; вторая шкала, здоровье, стамина, предметы инвентаря; переодевания, толпа, отвлекающие предметы; задержания, борьба, оружие; слова «мобилизация»/«бусификация». Всё из «Не входит» README расширения остаётся в силе.

**Правило внедрения:** минимальные обратимые правки. Новые узлы — отдельные скрипты в `game/stealth/`, подключение — через существующие сигналы и `DemoWorld`; рефакторинг постороннего кода «заодно» не делать.

## 4. Проход игрока

Было и остаётся: `Бабка (!) → квест → машина → киоск → покупка → машина → Бабка (?) → сдача`.

Вставка только в пешем переходе: `парковка (STEALTH_CHECKPOINT) → [участок с укрытиями] → окно продавщицы → существующая покупка`. На обратном пути укрытия работают, новых обязательных этапов нет; провал после покупки хлеб не отнимает и диалог покупки не повторяет.

Схема потоков (не геометрия):

```text
      [парковка / STEALTH_CHECKPOINT (66, −88)]
                    |
   ┌────────────────┼─────────────────┐
[сугроб]        [полицейский]      [коробка]
у гаражей       OFFICER_POST       у гаражей,
(запад)         конус 9 м / 75°    ближе к киоску
   └────────────────┼─────────────────┘
                 [бочка]
          у контейнеров KioskBins
                    |
          [окно продавщицы VENDOR_WINDOW (59, −77)]
```

Требования к размещению: минимум два читаемых пути; ничего на `ROUTE_WALK` (x = 66), в проезде улицы B, на пути автобуса `VAN_PATH`, в `KIOSK_ZONE`-триггере прибытия и у окна продавщицы; патруль и укрытия видны с парковки заранее; конус не возникает под ногами при респавне. Наборы `STUCK`, `GREY01`, `DRIVE01` остаются зелёными.

Ориентиры для первого размещения (уточнить при реализации): коробка — у восточной стены гаражей `Garages_Kiosk` между гаражами и киоском (≈ x 51, z −72); сугроб — у той же стены южнее, ближе к парковке (≈ x 51.5, z −90); бочка — у контейнеров `KioskBins` (≈ x 54, z −66). Точки — только `layout.gd` (C1): `BREAD_BOX`, `HIDE_SNOWDRIFT` (центр, `anchor`, `exit`), `BARREL`.

## 5. Зрение и заметность

### 5.1. Сенсор

`DetectionSensor` остаётся единственным местом геометрии зрения. Добавляется множитель: `visibility()` возвращает `видимость(0|1) × exposure`, где `exposure` — коэффициент заметности текущего состояния Илюши (раздел 5.3). Опрос — прежние 0,15 с, в `_physics_process`, без `Timer` на кадр и `await`. Случайности нет: один путь — один результат.

Точка цели луча при укрытии в сугробе — якорь укрытия (Илюша внутри меша сугроба); правило `exposure = 0` в сугробе делает результат луча неважным, но луч не должен ошибочно упираться в сам декоративный сугроб и считать это «укрыт» для других сенсоров — коллизия сугроба-укрытия лежит на слое World, как павильон, и честно перекрывает луч.

### 5.2. Шкала

`StealthDirector` без изменений структуры: рост `delta / RISE_SECONDS × exposure`, спад прежний, `max` по сенсорам, `frozen` при диалоге, паузе и провале. Ни один новый узел не пишет в `suspicion` напрямую.

### 5.3. Коэффициенты заметности (начальные)

| Состояние Илюши | exposure вдали | в радиусе 1,5 м от глаз наблюдателя |
|---|---:|---:|
| обычный | 1,0 | 1,0 |
| в коробке, стоит | 0,0 | 0,5 |
| в коробке, идёт | 0,75 | 0,75 |
| в сугробе | 0,0 | 0,0 |
| в бочке, стоит | 0,0 | 0,5 |
| в бочке, катится | 1,0 | 1,0 |

«Стоит» — горизонтальная скорость < 0,1 м/с. Если луч перекрыт стеной — 0 независимо от состояния. Торчащий из сугроба ботинок — только юмор, на правила не влияет.

### 5.4. Визуализация

Конус на земле — существующий `show_cone` сенсора: включать при входе Илюши в 40 м (`ACTIVE_DISTANCE`), выключать при удалении. Конус — картинка вычислений, не зона, которая ловит. Отладочный флаг `debug_cones` — вывод range / fov / LOS / exposure / suspicion в консоль, по умолчанию выключен.

## 6. Механика 1 — коробка «БАТОНЫ»

**Принцип:** мастер маскировки под оптовую поставку хлеба.

**Объект:** `game/stealth/box_hide_spot.gd` — `Interactable` с `interaction_id = &"bread_box"` плюс облик: картонный короб ≈ 1,0 × 1,2 × 0,8 м с надписью «БАТОНЫ» (`_label`, как таблички остановки), снег на крышке. Строится `LevelGeometry` по `Layout.BREAD_BOX`.

**Сценарий:**
1. Подсказка `E — НАДЕТЬ КОРОБКУ`.
2. `Ilyusha.hide_mode = &"box"`: облик коробки — дочерний `Node3D` у `player.visual`, спрайт Илюши скрыт; предел скорости 1,2 м/с (0,3 × `WALK_SPEED`; в исходнике 0,55 м/с при другой базовой скорости); прыжок запрещён; объект-коробка в мире скрыт.
3. Стоя — не видят вдали; на ходу — заметна (5.3).
4. `E — СНЯТЬ КОРОБКУ`: коробка возвращается в `Layout.BREAD_BOX`, дубликатов нет.
5. В коробке нельзя сесть в машину, купить хлеб, начать диалог: вместо молчания — подсказка `СНАЧАЛА СНЯТЬ КОРОБКУ` в строке подсказки HUD; зоны Бабки, продавщицы и двери «Лады» при `hide_mode != &"none"` подсказку меняют, `interacted` не вызывают.
6. При провале и респавне `hide_mode = &"none"`, коробка на месте, блокировок не остаётся.

**Реализация:** движение остаётся в `Ilyusha._physics_process`; добавляются `hide_mode: StringName` и `speed_limit()`. Новой системы предметов нет.

**Гэги** (субтитры, см. раздел 9): C02 — коробка стоит, C03 — коробка идёт; при попытке купить хлеб в коробке — подсказка `ПРОДАВЩИЦА: «Оптовикам не продаю. Вылезайте»` одной строкой субтитра без открытия диалога.

## 7. Механика 2 — сугроб-укрытие

**Принцип:** Илюша изображает элемент благоустройства.

**Объект:** `game/stealth/snow_hide_spot.gd` — `Interactable` `&"snowdrift"`; облик — грязный сугроб ≈ 2,4 × 1,4 × 1,6 м у стены гаражей (цвета как у валов ART-02), коллизия на слое World. Точки `Layout.HIDE_SNOWDRIFT`: центр, `anchor` внутри, `exit` — свободная точка перед сугробом вне конуса `OFFICER_POST` при любом из его `OFFICER_FACING`.

**Сценарий:**
1. `E — ЗАРЫТЬСЯ`.
2. `player.place(anchor, yaw)`, `hide_mode = &"snowdrift"`, движение и прыжок запрещены, спрайт Илюши скрыт, снаружи — ботинок (дочерний объём) и короткий всплеск снежной пыли (как брызги PLAY-03).
3. Пока прячется — `exposure = 0`; шкала спадает по общим правилам, не обнуляется мгновенно.
4. `E — ВЫЛЕЗТИ`: выход в `exit`, если точка свободна (проверка `_free_exit_spot`-подобная, как при выходе из машины); занята — подсказка `ВЫХОД ЗАНЯТ`, Илюша остаётся внутри.
5. При провале, паузе и перезапуске мира Илюша гарантированно извлечён; видимость и коллизия восстановлены.

**Гэги:** C04 при развороте патруля в сторону сугроба, пока Илюша внутри; при выходе — тост `ВЫ ВЫЛЕЗЛИ ИЗ КЛИМАТИЧЕСКИХ УСЛОВИЙ` (через `stealth_toast` HUD, 2,5 с).

## 8. Механика 3 — бочка

**Принцип:** секретный транспорт с очень плохой маскировкой.

**Объект:** `game/stealth/barrel_hide_spot.gd` — `Interactable` `&"barrel"`; облик — ржавая бочка Ø 0,9 м, высота 1,2 м, у контейнеров. Точка `Layout.BARREL`.

**Сценарий:**
1. `E — ЗАЛЕЗТЬ В БОЧКУ`.
2. `hide_mode = &"barrel"`: ввод прежний (стики/WASD), предел скорости 2,6 м/с, ускорение как у ходьбы, прыжок запрещён; облик бочки лежит на боку и вращается на угол `пройденный путь / радиус`, спрайт Илюши скрыт.
3. Стоя вдали — не видят; катится — заметна (5.3). Остановка резкая, спад шкалы — по общим правилам.
4. Удар о стену: `move_and_slide()` останавливает, вращение прекращается вместе с фактическим движением; один звук `БУМ` (синтез `generate_audio.py`, `barrel_bump.wav`) с паузой ≥ 4 с; дребезжание при качении — короткий зацикленный `barrel_roll.wav`, громкость по скорости.
5. `E — ВЫЛЕЗТИ ИЗ БОЧКИ` — только в свободную точку рядом; в бочке нельзя сесть в машину и купить хлеб (подсказка `СНАЧАЛА ВЫЛЕЗТИ ИЗ БОЧКИ`).
6. При провале бочка возвращается в `Layout.BARREL`, маршрут не перегораживает.

**Техническое решение:** бочка — визуальная оболочка над `CharacterBody3D` Илюши, не `RigidBody3D`. Капсула Илюши (радиус `PROBE_RADIUS` 0,5) уже узких проходов: сверить, что визуальная бочка Ø 0,9 м не входит в стены в проходах у гаражей; при необходимости в режиме бочки увеличить радиус коллизии до 0,45 м или не ставить бочку у узких проходов.

**Гэги:** C05 при качении в конусе; C06 `БОЧКА ПРИБЫЛА` + Илюша «Ну всё» — при первом ударе.

## 9. Состояния и контракты

```text
Ilyusha.hide_mode:   &"none" ── &"box" | &"snowdrift" | &"barrel"   (в один момент одно)
StealthDirector:     safe ──видят──> suspicious ──1.0──> alert → экран провала → респавн → safe  (без изменений, C7)
MissionDirector:     только чтение (has_bread, state) — укрытия не пишут
```

Переходы `hide_mode` запрещены, если `DemoWorld.control_mode == &"in_car"`, открыт диалог (`QuestFlow.is_dialog_open()`), идёт провал (`DemoWorld.is_stealth_failing()`) или `ui_blocking`. Вход в машину, диалог и покупка запрещены при `hide_mode != &"none"` (подсказка вместо действия).

| Источник | Контракт | Получатель |
|---|---|---|
| `Ilyusha` | `hide_mode: StringName`, `exposure_factor(eye_position) -> float`, `speed_limit() -> float` | `DetectionSensor`, HUD |
| `DetectionSensor` | `visibility() -> float` 0…1 (было 0 или 1) | `StealthDirector` |
| `*HideSpot` (`Interactable`) | `interacted` → `enter(player)` / `exit(player)`; `reset()` | `DemoWorld` (`respawn_at_checkpoint`, `reset_car`-подобный сброс) |
| `StealthDirector` | `player_detected`, `state_changed` | без изменений |
| `MissionDirector` | `has_bread`, `state`, `bread_received` | только чтение |
| `DemoWorld.get_hud_state()` | + `hide_mode`, `hide_hint` (подсказка-отказ) | `GameHud` |

Подсказки зон укрытий выставляет сам `HideSpot` (они не зависят от этапа миссии), остальные зоны — по-прежнему `MissionDirector.prompt_for` (C3).

## 10. Структура в проекте

Сцены собираются кодом (`LevelGeometry`, `Patrols`), поэтому новые узлы — тоже кодом, без `.tscn`:

```text
DemoWorld
├── Player (Ilyusha)            # + hide_mode, speed_limit, exposure_factor; облики укрытий — дети visual
├── StealthDirector             # без изменений
├── LevelGeometry
│   ├── Patrols                 # EXT-01 N: Officer, AccountOfficer, CityVan
│   └── HideSpots (new, game/stealth/hide_spots.gd)
│       ├── BreadBox   (box_hide_spot.gd)
│       ├── Snowdrift  (snow_hide_spot.gd)
│       └── Barrel     (barrel_hide_spot.gd)
└── GameHud → SuspicionMeter    # + строка подсказки-отказа
```

Скрипты: `hide_spot.gd` — общий предок (`Interactable` + облик + `enter/exit/reset`); три наследника; изменения в `ilyusha.gd` (режим, предел скорости, запрет прыжка), `detection_sensor.gd` (множитель), `demo_world.gd` (сброс при респавне, запреты входа в машину, HUD-поля), `quest_flow.gd` — только проверка `hide_mode` перед открытием диалога (одна строка), `lines.gd` — тексты гэгов. Фреймворков и плагинов не делать.

## 12. Расхождения с исходным ТЗ и каноном расширения

- Исходник: дистанция 10 м, защита 2,5 с, fail ≤ 3 с. У нас 9 м, 4,0 с, 2,0 с (C7) — не менять.
- Исходник: скорость в коробке 0,55 м/с, в бочке 2,2 м/с. У нас базовая ходьба 4,0 м/с (PLAY-02), поэтому 1,2 и 2,6 м/с; уточнять по плейтесту «участок 45–90 с».
- Исходник: гэги как диалоги с рацией. У нас — субтитры, диалоги остаются только у Бабки, продавщицы, полицейского и сотрудника ГСУМ (EXT-01 L).
- Исходник: C07 добавляет диалог при провале. У нас провал без диалога (без сцен задержания — README расширения).
- Исходник: «старые сохранения». В проекте сохранений нет — пункт снят.
- Исходник: мини-карта и HUD задания «оставить» — остаются как есть; индикатор подозрения уже существует.

## 14. Приёмка

**A. Регрессия (блокирует):** `make test` 0 failures: SMOKE, MISSION, GREY01, DRIVE01, QUEST01, AUDIO, STUCK, ART01, DEMO_ACCEPTANCE, STEALTH без правок ожиданий, кроме текстов подсказок; сквозной проход 01→10 вручную; хлеб только флаг `has_bread` и пиктограмма HUD; награда один раз.

**B. Зрение:** вне дистанции и угла — 0; стена, гаражи, киоск, павильон, контейнеры, «Лада», автобус, сугроб-укрытие перекрывают луч; при открытом диалоге и паузе — рост 0; одно обнаружение — один экран провала; после респавна 4 с без роста; на 30 и 60 к/с время до обнаружения ≈ 2,0 с (± 1 кадр).

**C. Коробка:** надеть/снять всегда доступны в допустимом состоянии; стоя вдали — 0, на ходу 0,75, в 1,5 м стоя — 0,5; нельзя купить, сесть в машину, открыть диалог — подсказка; после провала одна коробка на месте.

**D. Сугроб:** войти/выйти; внутри движения нет; exposure 0; выход в свободную точку вне конуса; после провала и перезапуска Илюша снаружи, видим, управляем.

**E. Бочка:** вход/выход; стоя вдали 0, катясь 1,0; стена останавливает, нет провала под карту и разгона; вращение и звук — по фактическому пути; после выхода скорость `WALK_SPEED` и прыжок возвращены.

**F. Демо:** ровно три укрытия и коэффициент заметности, ничего сверх; участок проходится каждым укрытием; патруль виден заранее, два пути свободны; нет softlock при любой последовательности укрытий (20 входов/выходов — без утечки узлов, скорость прежняя); первый проход 45–90 с (ориентир); повтор после провала без повторной покупки; гэги не чаще лимита, не копируют реплики ШКЯ; запрещённых слов нет (проверка по всем `HIDE_*`, как в QUEST01); `make fps` ≥ 100 среднее.

**Крайние случаи:** коробка + E у двери «Лады» → подсказка, не посадка; в сугробе патруль смотрит на выход → ждём, выход сам не происходит; бочка в стену → вращение стоит; диалог закрыт в момент роста → шкала не прыгает; обнаружение в тик покупки → покупка атомарна, не откатывается; провал и диалог одновременно не открываются; возврат с хлебом через участок → `has_bread` не меняется.
