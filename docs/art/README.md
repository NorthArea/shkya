# Концепт-кадры ШКЯ: Ничего необычного

Концепты — ориентиры игрового процесса, а не готовые слои, спрайты, текстуры или карты коллизий. PNG хранятся без изменений. Если кадр расходится с текстом, действует текст (порядок — [docs/README.md](../README.md)); решения владельца, перекрывающие кадры (тонкий контур, лицо Бабки, куржак, город Н.), — [DECISIONS.md](../DECISIONS.md).

Итоговый облик, который есть в игре: персонажи — [CHARACTERS.md](CHARACTERS.md), город — [CITY.md](CITY.md). Референсы персонажей — мультфильмы Евы Морозовой V01, V02 ([референсы](../SHKYA_NOVOSIBIRSK_AGENT_REFERENCES.md)); V04 — только для сюжета и реплик.
