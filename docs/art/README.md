# Концепт-кадры ШКЯ: Ничего необычного

Концепты — ориентиры игрового процесса, а не готовые слои, спрайты, текстуры или карты коллизий. PNG хранятся без изменений. По последнему уточнению MSG-0138 главный эталон Илюши — наш прежний утверждённый 2D-облик в `assets/art/characters/ilyusha_*`: его переносим в настоящий объём. PNG01–10 служат дополнительными ракурсами при согласии с этим обликом. Если кадр расходится с текстом, действует текст (порядок — [docs/README.md](../README.md)); решения владельца, перекрывающие кадры (тонкий контур, лицо Бабки, куржак, город Н.), — [DECISIONS.md](../DECISIONS.md).

Итоговый облик, который есть в игре: персонажи — [CHARACTERS.md](CHARACTERS.md), город — [CITY.md](CITY.md). Референсы персонажей — мультфильмы Евы Морозовой V01, V02 ([референсы](../SHKYA_NOVOSIBIRSK_AGENT_REFERENCES.md)); V04 — только для сюжета и реплик.

## Референс атмосферы от владельца

[167111322512708800.webp](references/167111322512708800.webp) — оригинал из загрузок владельца, добавлен 30.10.2026 без изменений. Ориентир для атмосферы и поведения жителей: у каждого своя позиция и занятие, повседневный абсурд существует внутри общего мира. Задача — много горожан со своими делами и связный город без ощущения арены-коробки с декоративным задником. Решение — [DECISIONS, «Город: арена»](../DECISIONS.md).

Автор и лицензия изображения не установлены; это референс, в игровые текстуры он не переносится.

[Полная подборка «ШКЯ» от владельца](references/ШКЯ/) — 14 файлов из `~/Downloads/ШКЯ`, скопированы 30.10.2026 с исходными именами и без изменений; состав и SHA-256 каждого файла сверены с источником. Используется для разнообразия лиц, силуэтов и одежды полицейских, ОМОНа и гражданских в рисовке ШКЯ (ART-09). Подборка хранится как визуальный референс; игровые рисунки создаются в существующей системе SVG проекта.

Игровые ассеты и их источники — [assets/README.md](../../assets/README.md).

- [Пять вариантов собственной рисовки Илюши,02.11](explorations/ilyusha/2026-11-02-five-styles.png) — отдельный лист поиска; [промпт](explorations/ilyusha/2026-11-02-five-styles.prompt.txt) и JSON происхождения лежат рядом.
