# Acceptance tests

## Функциональные
- [ ] Можно пройти всю исходную миссию, не перезапуская игру.
- [ ] Патруль обнаруживает игрока лишь при попадании в дальность, угол и прямую видимость.
- [ ] Стена или будка перекрывает линию зрения; низкий декоративный снег — нет.
- [ ] При выходе из конуса шкала тревоги уменьшается и сбрасывается.
- [ ] До киоска всегда доступны минимум два честных пути.
- [ ] На экране покупки прогресс стелса заморожен.
- [ ] После покупки флаг `has_bread` установлен; предмет не отображается в руках.
- [ ] При провале до покупки хлеб отсутствует, после покупки сохраняется.
- [ ] Чекпоинт никогда не ставит игрока внутрь поля зрения без возможности выхода.
- [ ] После возвращения жёлтый `?` появляется над Бабкой и квест завершается однократно.
- [ ] Дружинник отсутствует в сценах, спавнерах, репликах и документации игрового билда.
- [ ] Игра нигде не называет Город Н настоящим Новосибирском.

## UX / баланс
- [ ] Первый обязательный проход мимо патруля занимает ~45–90 секунд, а не минуты ожидания.
- [ ] На расстоянии до конуса игрок способен увидеть опасность.
- [ ] После провала потеря времени не более 10–20 секунд плюс повтор самого участка.
- [ ] Не более 5–7 ключевых реплик за миссию; повторы не звучат при каждом кадре.
- [ ] ФПС не падает ощутимо от двух наблюдателей и одной маршрутной машины.
- [ ] Игра проходима без знания слова «бусификация»; политический смысл считывается только вторым слоем.

## Художественные и юридические ограничения
- [ ] Все исходные изображения, голоса и характерные персонажи ШКЯ используются публично только после согласования лицензии.
- [ ] В данном пакете нет графических ассетов и чужих текстов.
- [ ] Нет реальных эмблем/маркировок конкретных подразделений; город и ведомство вымышлены.
