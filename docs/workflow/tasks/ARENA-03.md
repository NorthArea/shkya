**Ближайшая веха (по независимому кодовому аудиту):**
- A — ограниченные следы жителей у камеры в существующем SnowTracks; не на дороге/в воздухе/при скрытии, без новых коллизий. Владелец: bags; scope только snow_tracks и новый arena03_tracks_test.
- B — общение и домино с реальным партнёром; одиночный ждёт, при уходе/сбивании пара распадается. Владелец: arena_life; scope Life/Resident и новый arena03_life_test; стабильный API для последующей причинной озвучки.
- C — причинный звук входов и ветер: отдельная сессия владеет только SoundDirector/arena03_audio_test; Resident.entrance_used(resident, at, entering) — API от arena_life. Нет событий — нет хлопков, ветер следует Lighting.gust в прежнем миксе.
- Далее — единые видимые входы магазинов/домов и хлопки реальных дверей; читаемые лопата/выбивалка/капот и один ковёр; связь ветра с Lighting.gust; точечное обживание Z15/H11. Данные дверей/путей только Layout, сломанные опоры учитывают состояние Breakables.
**Открыто:** обзорные кадры C/D/Z6/Z15/Z18/Z20 и реальные маршруты; кодовый аудит не заменяет визуальную приёмку. CITY-03/DOG-01/PHONE-01 интегрируются прежде итоговой квалификации арены.
