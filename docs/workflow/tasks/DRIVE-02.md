# DRIVE-02 — Простая физика «Лады» по сугробам

Поручение владельца 29.10.2026 (день): «сделай простенькую физику для машины, чтобы можно было по сугробам ездить». Сейчас валы и сугробы (`Layout.SOLIDS` kind `snow`/`snow_bank`, `snow_banks()`) — твёрдые коробки слоя World: «Лада» упирается в них как в стену.

Результат: «Лада» въезжает на валы и сугробы и съезжает с них, как по рыхлому снегу: корпус поднимается по профилю сугроба, кренится и клюёт носом по высотам четырёх колёс, в глубоком снегу теряет скорость (сопротивление пропорционально глубине погружения), буксует с места на крутом склоне, при съезде слегка подпрыгивает; из-под колёс летит снежная пыль (шейдер брызг PLAY-03/KNOCK), след остаётся (trail). Пешеходы (Илюша, жители, патрули) по-прежнему не проходят сквозь валы (их маска World остаётся). Транспорт кольца и ГСУМ валы не трогают (едут по полосам).

## Контракт (C10)

- **Одна форма для вида и физики.** Новый `game/world/snow_field.gd` (`SnowField`, static): `height_at(x, z) -> float` — высота снега над землёй по всем сугробам `Layout` (SOLIDS kind snow/snow_bank + `snow_banks()`): для коробки размера (sx, sy, sz) профиль — скруглённый гребень `sy · smoothstep` от кромки к оси с детерминированным шумом по seed индекса (как `_lumpy_bank`), за пределами коробки + 0,6 м — 0; `normal_at(x, z)`; `depth_at` для сопротивления. Часть E (CITY-02) строит меш валов **по этой же функции** (`SnowField.height_at`), чтобы колёса стояли на видимой поверхности (расхождение ≤ 5 см).
- **Коллизии.** Коробки snow/snow_bank переводятся на отдельный слой 7 (64, «SnowBank»): маска «Лады» его не включает, маска Илюши/жителей/патрулей/собаки — включает (пешеходам — стена, как раньше). `Layout.all_solids()` и тесты STUCK/GREY01 — без правок ожиданий (для «Лады» вал больше не тупик; сценарии застревания у валов остаются зелёными или становятся проще). Проверить лучи стелса (`_sight_ray` маска World|Car): валы на слое 64 перестанут заслонять обзор — вернуть их в маску луча (`DetectionSensor`) — так остаётся как было.
- **Движение.** В `lada.gd` после `move_and_slide()`: целевая высота `y = SnowField.height_at` под центром + клиренс; подъём/спуск со сглаживанием (пружина, не телепорт), по четырём колёсам — крен/тангаж корпуса (поворот `Visual`, не тела); сопротивление `SNOW_DRAG · depth` (глубина погружения колеса), на склоне круче `MAX_CLIMB` (≈ 35°) против движения — буксование (скорость → 0 с пробуксовкой); «прыжок» при резком падении высоты > 0,3 м — короткий отрыв (velocity.y) и мягкая посадка; камера за авто — без рывков (пружина как есть).
- **Эффекты.** Пыль из-под колёс при depth > 0,1 и скорости > 2 м/с; звук шуршания снега (синтез, `generate_audio.py` `snow_drive_loop`) по глубине; след по снегу (trail) на валу.
- **Границы.** Площадка киоска `KIOSK_SQUARE` и стелс C7: въезд на валы у киоска не создаёт новых обходов — проверить STEALTH; «правило крыши» (y > 1,5 м в ROOF_AREA) не ловит машину на валу — валы ниже 1,5 м; при необходимости правило дополнить (валы не крыша).
- **Тесты.** Набор DRIVE02 (`tests/drive02_snow.gd`): «Лада» переезжает вал A с 8 м/с (высота корпуса следует `height_at` ±0,1 м, крен ≠ 0, скорость падает), с 1 м/с на крутой склон — буксует, съезд — без застревания; Илюша и житель в вал не проходят; STUCK, DRIVE01, GREY01, QUEST01, STEALTH, TRAFFIC, RESIDENTS, KNOCK, COINS, BREAK — 0 failures без правок ожиданий; `make fps` без потерь (>−1 к/с).

## Дополнение 29.10 (решение владельца по DRIVE-03, вариант A)

В объём DRIVE-02 входит «вкус» аркады: подвеска-покачивание корпуса (пружина по вертикали и по крену при разгоне/торможении/поворотах — перенос веса: нос клюёт при торможении, корма приседает при разгоне, крен наружу в повороте, всё через поворот `Visual`, не тела), дым из-под колёс и следы заноса при ручнике/боковом скольжении (шейдер следа trail + частицы/спрайты как пыль), отскок при ударе о разрушаемые объекты и машины (короткий импульс назад и тряска камеры, без урона), скрип при заносе (синтез). Ощущение PLAY-02 (разгон, торможение, руль) не меняется — те же константы.
