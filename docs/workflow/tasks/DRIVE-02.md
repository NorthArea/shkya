# DRIVE-02 — Простая физика «Лады» по сугробам

Статус: review (29.10) — влита поверх CITY-02 E (1210406), ждёт игры владельца.

**Результат.** Поручение владельца 29.10: «сделай простенькую физику для машины, чтобы можно было по сугробам ездить». «Лада» въезжает на валы и сугробы и съезжает с них как по рыхлому снегу: корпус идёт по профилю, кренится и клюёт по высотам колёс, в глубоком снегу теряет скорость, на крутом склоне буксует, при съезде подпрыгивает; из-под колёс летит пыль, на валу остаётся след. Для пешеходов валы — по-прежнему стена; транспорт кольца и ГСУМ едут по полосам. По решению владельца по DRIVE-03 (вариант A) сюда же входит «вкус» аркады: подвеска и перенос веса, дым и следы заноса, отскок от препятствий, скрип; ощущение PLAY-02 (разгон, торможение, руль) не меняется.

**Файлы.** `game/world/snow_field.gd`, `game/vehicles/lada.gd`, `game/vehicles/lada_fx.gd`, маски — `game/player/ilyusha.gd`, `game/npc/*.gd`, `game/stealth/*` (сенсор и укрытия), `game/world/demo_world.gd`; `project.godot` (слой 7 «SnowBank»), `game/audio/sound_director.gd`, `tools/generate_audio.py` (`snow_drive_loop`, `skid_squeak_loop`), `tests/drive02_snow.gd`.

**Интерфейсы.** Контракт — C10 SnowField в `docs/workflow/README.md`: одна форма валов для вида (CITY-02 E) и колёс, слой 7 (64) для коробок snow/snow_bank, маски World|Car|Breakable|SnowBank у пешеходов и в лучах стелса, границы у киоска. Эффекты `lada_fx.gd` — только облик, на физику не влияют.

**Критерии.** Высота корпуса на валу следует `SnowField.height_at` в пределах ±0,1 м, крен ≠ 0, скорость в снегу падает; с 1 м/с на крутой склон — буксование; съезд без застревания; Илюша и жители в вал не проходят. Новых обходов стелса у киоска нет. Прочие наборы — без правок ожиданий; `make fps` без потерь.

**Проверка.** DRIVE02, STUCK, DRIVE01, GREY01, QUEST01, STEALTH, TRAFFIC, RESIDENTS, KNOCK, COINS, BREAK; `make fps`.
