# PAD-02 — независимые педали при рулении стиком

Статус — [backlog](../backlog.md); решение — [DECISIONS](../../DECISIONS.md), «Управление».

- **Баг:** RT + правый поворот замедляет машину, левый — нет. Проверка исходника нашла общие действия ходьбы/педалей: вертикальная диагональ стика включала тормоз.
- **Правка:** отдельные `car_gas`/`car_brake` в обоих автомобильных контроллерах; пеший Y остаётся в ходьбе. W/S, A/D и кнопки геймпада сохранены; коэффициенты физики не менялись.
- **Независимая приёмка:** настоящие InputEventJoypadMotion → InputMap → Lada, ровная площадка, зеркальные повороты, три силы газа, обе вертикальные диагонали, порядок RT→Y/Y→RT/отпускание Y, LT/обе педали, клавиатура и неподвижный руль. После исправления устройства фикстуры RED58 → GREEN0.
- **Сохранённая регрессия:** `tests/pad02_symmetry_test.gd`; логи/CSV/JSON — `builds/checks/PAD-02/`. Ошибочный DEVICE7-первый прогон отдельно сохранён и не принят как доказательство игрового бага.
- **Штатная регрессия:** PAD02 200/0, DRIVE01 51/0, PLAY04_CAR 147/0, PAD01 135/0; мигрированы только автомобильные ветви помощников, пешие сохранены. Pin измерителя и ожидания deadzone обновлены по независимой проверке точного diff; исходные 144 поведенческих assertions сохранены.
- **Остаток:** проверка владельцем на физическом геймпаде. Этот oracle не аттестует мир и физику raycast-прототипа.
