# ART-07 — Полицейский и «военком» по сетке концепта

Статус: review (29.10) — ждёт игры владельца.

**Результат.** Полицейский и «военком» в игре узнаются как на e03/e01 — с игровой камеры, а не по листу SVG (решение владельца 29.10, ночь, LOOK-01: после игры он не видел сходства). Композиция форм концепта: широкое плоское лицо, ушанка уже лица и сидит на голове, блокнот сбоку, тело — высокий скруглённый прямоугольник.

**Файлы.** `tools/generate_characters.py` (police/officer, константы `P_*`/`O_*`), `assets/art/characters/police_*`, `officer_*`.

**Интерфейсы.** Имена обликов `police`, `officer` и три ракурса не меняются; контур тонкий `LINE` (решение владельца 28.10). Облик персонажей — `docs/art/CHARACTERS.md`.

**Метод** (им же пользуется ART-08). Кроп концепта приводится к холсту 400×600 по росту фигуры — только во временном каталоге сессии, не в репозиторий; с кропа снимаются координаты форм и цвета; формы переносятся в константы генератора; SVG → PNG того же размера накладывается на кроп; затем кадры из игры рядом с концептом.

**Критерии.** Расхождение масок с кропом: силуэт ≤ 10 %, лицо ≤ 15 %. ΔL фигуры к фону ≥ 0,12 за счёт кромки-инея, палитра шинели — по канону. Независимая сверка по кадрам из игры (3/6/10 м, диалог) — «похож». Последнее слово — владелец после игры.

**Проверка.** ART01 (60 и 120 к/с), QUEST01, DEMO_ACCEPTANCE, STEALTH, RESIDENTS.

**Сделано / открыто.**
- Проход 1 (e4c0488): сетка e03 → константы; ушанка на голове, широкое лицо, блокнот сбоку, тело-прямоугольник, кромка-иней; «военком» в 3/4 с планшетом. Сверка по кадрам: оба «похож».
- Проход 2 (597dc7b): клапаны ушанки сплошной массой, кромка только у ушанки и плеч, прищур; у «военкома» квадратные плечи с погонами, папка в левой руке. Цели по маскам выполнены. Попутно — облик `ushanka_walk` для пассажира остановки A.
- Остатки P3 ушли в ART-08. Открыто: игра владельца.
