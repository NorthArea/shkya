# ART-07 — Полицейский и «военком» по сетке концепта

Результат: полицейский и «военком» в игре узнаются как на e03/e01 на взгляд владельца. Три сверки по пропорциям дали «похож», но владелец после игры сходства не видит; LOOK-01 показал, что сверки не ловили композицию форм: у концепта лицо широкое и плоское, ушанка уже лица и сидит на голове, блокнот сбоку, тело — высокий скруглённый прямоугольник; у нас ушанка-шар шире тела и узкое лицо. Решение 29.10 (ночь): перерисовать по сетке концепта с наложением, принимать по наложению и по кадрам из игры, а не по листу.

Владелец: root. Зависимости: LOOK-01 B (контур ×2, мипмапы, камера). Файлы: `tools/generate_characters.py` (police/officer и помощники), `assets/art/characters/police_*`, `officer_*`.

## Метод

1. Кропы концепта (e03 — обе фигуры, e01 — полицейский крупно) привести к холсту 400×600 по росту фигуры (ноги на 580, верх убора на 20) — только во временном каталоге сессии, не в репозиторий.
2. Снять с кропа координаты ключевых форм: убор (ширина/высота/посадка), лицо (ширина/высота/форма верха и низа), шея, плечи, тело (ширина по груди/низу, высота), руки и предметы (блокнот, планшет), ноги/обувь, цвета пипеткой.
3. Перенести в генератор 1:1 (константы форм), сохранив тонкий контур `LINE` (решение владельца) и три ракурса.
4. Проверка наложением: SVG → PNG того же размера, полупрозрачно на кроп; расхождение силуэта (XOR масок) ≤ 10 % площади фигуры, лица ≤ 15 %. Затем кадры из игры с игровой камеры (диалог, 3/6 м) рядом с концептом.
5. Тёмный на тёмном: палитру шинели не менять (канон), но добавить светлую кромку силуэта в SVG (тонкая холодная подсветка по краю, как иней) или чуть светлее средний тон, чтобы ΔL к фону ≥ 0,12.

## Приёмка

Независимая сверка по наложению и по кадрам из игры (не по листу): «похож / не похож», числа XOR; ART01 14/0 на 60 и 120; QUEST01, DEMO, STEALTH зелёные; игра владельца.
