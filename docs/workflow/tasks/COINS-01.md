# COINS-01 — Монетки: 35 рублей до батона

Результат: стартовых денег нет (`START_MONEY` 0); по городу разложены монеты (рубли) — у подъезда, во дворе, вдоль маршрута к киоску, на площадке, у остановок, в проходе у гаражей; Илюша собирает их касанием (пешком и на машине — монеты на дороге), счётчик монет в HUD рядом с карточкой задачи (пиктограмма монеты + число / 35), звук сбора (синтез, как в аркадах); продавщица продаёт только при ≥ 35 («Батон — 35 рублей. У вас…» уже есть логика `can_buy_bread`); подсказка HUD «Собери 35 монет» до набора; монеты из сбитых дронов (PUNCH-01) — по 5. Референс идеи — монеты *Hit & Run* (решение владельца 29.10). Монеты — простой объём (жёлтый диск с «₽», вращается, светится), без чужих ассетов.

Владелец: root; исполнитель — агент. Зависимости: нет; PUNCH-01 подключает дроп. Файлы: `game/mission/mission_director.gd` (`START_MONEY` 0, `add_money(n)`, сигнал `money_changed`, задача «Собери монеты» в `objective()` при деньгах < 35 в состоянии BUY_BREAD… и раньше — уточнить по FSM: сбор возможен с самого начала), `game/world/coins.gd` (узел `Coins`, точки — `game/world/coin_layout.gd` новый файл (layout.gd заняты другими исполнителями; интегратор перенесёт в Layout, C1), ≥ 60 монет по городу так, чтобы 35 набирались по пути к киоску без обязательного крюка, но с одним-двумя соблазнами в сторону), `game/ui/game_hud.gd` (счётчик), `game/audio/sound_director.gd` (добавлением), `tools/generate_audio.py`, `tests/coins_test.gd` (набор `COINS`), обновление `tests/mission_director_test.gd`, `quest01_acceptance.gd`, `demo_acceptance.gd`, `stealth_test.gd` там, где они покупают хлеб (водитель должен собрать монеты или тест выдаёт деньги через `add_money` с пометкой).

Проверка: COINS (сбор пешком и на машине, счётчик, звук, 35 → покупка, < 35 → отказ с подсказкой, монеты не на дороге кольца и не в полосах, не внутри коробок, респавн не трогает), MISSION, QUEST01, DEMO_ACCEPTANCE, STEALTH, HIDE_*, STUCK зелёные; кадры: монеты во дворе, счётчик, сбор на машине.
