# CHARACTER-03 — прогноз контакта NPC и возврат к маршруту

Статус/исполнитель — [backlog](../backlog.md); основание MSG-0141 — [CHARACTER-01](CHARACTER-01.md).

- **Результат:** реальные Resident/Residents + герой/машина/соседние жители → прогноз сближения → bounded stop/yield/dodge/cringe → продолжение прежнего route/занятия → gait. Прогноз не создаёт новый граф/цели/население.
- **Первичный источник:** [3UR c84f9ff9ae9b27a5d34dca7985ac819e70f62bc6, `src/game/worldsim/character/charactercontroller.cpp`1114–1182,1294–1536](https://github.com/3UR/Simpsons-Hit-Run/blob/c84f9ff9ae9b27a5d34dca7985ac819e70f62bc6/src/game/worldsim/character/charactercontroller.cpp#L1114); возврат951–1103; `src/game/worldsim/ped/pedestrian.cpp`90–200 — peer stop/talk/yield. Navmesh/RVO в рассмотренном пути не найден; не выдавать за используемый механизм.
- **Назначение/владение:** root принял bounded predictor/API; npc_motion_mechanics разрешены только новый `game/npc/pedestrian_motion.gd` и developer tests. Root подключает `game/npc/resident.gd` после стабильной QA LOCOMOTION-01/IP-01; собственные developer tests helper не принимают реальную композицию.
- **Текущий пробел:** `_walk` сразу задаёт скорость; есть stop/reverse перед героем/Ладой и `_dodge_lada` после касания. Общего прогноза между жителями и явного bounded resume ещё нет; новые сценарии должны достигать этих границ.
- **Контракт до кода:** принятый `step(here, segment_start, goal, cruise_speed, footprint_offsets, obstacles, delta, can_step, allow_avoidance)` возвращает displacement; `suspend/reset`, readonly mode/threat_id. Residents поставляет снимок угроз кадра; канонический can_step решает доступность; явный canonical segment_start ограничивает offset исходным сегментом, чтобы обход не накапливал detour. Resident один владеет goal/route/state/бронью/knock; helper не телепортирует и не форсирует небезопасный прогресс.
- **Гарантии:** prediction отличает сближающуюся машину от удаляющейся; stop/yield/dodge имеют конечный выход и безопасный возврат на тот же путь. Проверять физически доступные локальные смещения; без teleport, исчезновения, обхода стены/снега и вечного ожидания. Контакт/KNOCK сохраняет высший физический приоритет; существующее crossing без остановки не превращается в ожидание из-за новой avoidance-логики.
- **Настоящие потребители:** Resident tick/ходьба, Residents/пары/пассажиры, Life/reservations/очереди и CharacterSprite/UniformVisual. Не потерять занятие/бронь/направление пары при реакции, не дублировать пассажира при boarding/alighting.
- **Согласование:** CHARACTER-05 изменяет activity/recovery и pose submit того же `resident.gd`; интеграцию03/05 выполняет один root последовательно. Независимые новые helpers/tests возможны после согласованной границы; concurrent broad edits Resident запрещены. CHARACTER-06 использует принятый prediction/return03.
- **Независимая QA:** встреча двух жителей, пересечение путей, неподвижный блокер, встречная/попутная/удаляющаяся машина, завершение ожидания, пара/пассажир, sparse LOD, reset и повторный контакт. Реальные сценарии + RESIDENTS/LIFE01/KNOCK/троллейбус/городская жизнь; критерии не выводить только из helper.
- **Ограничения/evidence:** действующие64жителя, реальные маршруты/границы, миссии, камера и C7/C8 сохраняются; свои код/ассеты. `builds/checks/CHARACTER-03/`, headless/Dummy; GPU/вид/ощущения/FPS отдельны, runtime пока не принят.
