# IP-01 — персонажи ШКЯ в настоящем 3D

Статус — [backlog](../backlog.md), решения — [DECISIONS](../../DECISIONS.md).

- **Илюша, MSG-0131:** точное воспроизведение образа PNG `docs/art/concepts/01…10` в настоящем3D. Старый SVG и его пропорции уступают концептам. Главный стоящий ракурс —02, перекрёстные силуэты/одежда/шаги —01/04/08; невыведенные из рисунка глубина и фронт остаются технической реконструкцией до просмотра.
- **Требуемая форма Илюши:** компактная розовая голова с высоким жёлтым безе/открытым крюком носа над длинным мягким пуховиком; дутые секции корпуса и рукавов, большой капюшон, мешковатый таз/брюки со складками, высокие зимние ботинки и кисти с пальцами.
- **Остальные:** прежние SVG/канон облика — основа лиц/одежды Бабки, продавщицы и всех типажей жителей; принятые police/guard не переизобретать. Исходные арты/SVG не удалять.
- **Потребители:** пеший герой, сюжетные NPC, жители, водитель2106, водитель/пассажиры троллейбуса, диалоговые портреты. Роли/население/коллизии и механики сохраняются.
- **Владение:** shkya_hero_rework — civilian_model; shkya_residents_rework — legacy_resident_models; shkya_likeness_director — независимые PNG/CPU сверки; car02_independent_acceptance — независимые concept guards; root — реальная композиция/посадка/capture/QA/Git/BUILD-03.
- **Резиденты:** цельные платки/мягкие уборы/пакеты, индивидуальная графика лиц/жесты/швы; ткань огибает реальные треугольники головы/пальто, штрихи привязаны к поверхности. Нормали отвечают плоскостям ткани.
- **Посадка:** ступни выше реального днища, голова под крышей, лицо не касается руля, кисти у настоящих хватов. Стоячий силуэт не сжимается ради салона; адаптируется сидячая поза.
- **Проверки:** существующие geometry/rig/runtime/seat/hero-details; отдельные coarse PNG guards вместо старых SVG-цветов/ширины Илюши. Последние не доказывают «1в1». Геометрия других героев сравнивается по SHA; нового автора не принимают по его собственным числам.
- **Evidence:** `builds/checks/IP-01/concept-ilyusha/`, `builds/screenshots/IP-01/concept-ilyusha/`; прежние отвергнутые итерации/FAIL — `likeness-v2/`. Capture metadata для Илюши ссылается на PNG-концепты.
- **Граница preview:** адресные покупка/поездка/сдача/сенсор/посадка проверяются в реальной Main. Полная C7-квалификация не завершена: долгие попытки остановлены и отмечены NOT_RUN, без переноса старого PASS.
- **Другие обязанности IP:** название «Город Н» пока не перенесено в application/config/name; сознательные цитаты и собственные реплики пересверяются с TEXT-01. Этот визуальный preview не закрывает эти части нового концепта; удаление прежних SVG остановлено.
- **Открыто:** просмотр владельцем с игровой камеры, точное художественное совпадение, GPU-контур/свет/окклюзия и C9/FPS. Без отдельного разрешения окон не открывать. BUILD-03 — preview для этого просмотра, не техническая или художественная приёмка всей игры.
