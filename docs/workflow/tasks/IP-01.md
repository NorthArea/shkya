# IP-01 — готовый качественный герой и анимация; внешний вид позже

Статус — [backlog](../backlog.md), решение MSG-0195 — [DECISIONS](../../DECISIONS.md).

- **Результат:** качественный готовый персонаж с готовыми анимациями из открытого Godot-проекта в настоящей игре. Внешность Илюши №4 отложена; эталон сохраняется.
- **Назначение:** сначала проверка оригинального upstream, затем интеграция visual/AnimationTree в существующие Player и Driver. Не менять физический root, настроенные управление/камеру/коллизии, роли и миссии.
- **Кандидат:** Quaternius IK Rigged, [Codeberg](https://codeberg.org/jamesonBradfield/Quaternius_IK_Rigged_with_animations), pin `0cc5dc351f4fffbe13a25381e73cb0a1aea67f47`, Godot4.6+, CC0 для модели/анимаций/сцен. Оригинал — `builds/references/quaternius-ready/`; ещё не принят по одному README.
- **Альтернатива:** [Kenney Starter Kit](https://github.com/KenneyNL/Starter-Kit-3D-Platformer), pin `3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0`, код MIT/ассеты CC0. Это простой робот с idle/walk/jump, без полноценного humanoid rig и отдельного run; служит сравнительным примером, не текущим выбором.
- **Владение:** hero_from_reference — квалификация upstream, затем `game/characters/imported_hero_visual.gd` и `imported_hero_driving.gd`, активы выбранного героя и адресные tests; root — интеграционный контракт/документы/Git; независимая QA — движение и регрессии. Новые области согласовать до записи.
- **Цепочка:** Player→CharacterSprite→UniformVisual.configure("ilyusha")→новый backend; Lada→Driver использует тот же нормализованный body. Сохранять configure/update_locomotion/reset_pose, LOD/XRay, occupant/sole/hand APIs и semantic bone aliases.
- **Масштаб:** постоянный intrinsic рост и опора на пол по Catalog, пешком/за рулём одинаковые. Не уменьшать тело ради салона; не менять длины костей и масштаб по кадрам.
- **Анимации:** оригинальные совместимые mesh/rig/клипы; простой корректный Idle/Walk/Jog/Sprint/Jump с плавными переходами и соответствием реальной скорости. Старые GAIT_HIPS_MEAN, stride clamp, ретаргет и foot solver по умолчанию не переносятся. Driver-поза/руль проверяются отдельно.
- **Проверка исходника:** нативные front/side кадры и движущаяся последовательность оригинальных клипов с исходной сценой, без нашей correction layer; лицензии и source hashes модели/анимаций/кода.
- **Приёмка интеграции:** реальный игровой Player — idle→ходьба/бег→stop/turn, jump/fall/land, hide/teleport/reset, вход/выход из машины; нормальная осанка, связные суставы, без скольжения/провалов/клиппинга и резких скачков. Независимая визуальная/техническая QA и ручной проход владельца; authored preview и средние FPS не принимают результат.
- **Проверки:** существующие поведенческие/контрактные оракулы переиспользовать; obsolete exact14/16/23 bone/one-mesh assumptions отвергаются отдельным обоснованием, не подгонкой критерия. Script checks headless; необходимые native проверки разрешены MSG-0189 через launcher с command-scoped GODOT_VISIBLE_CHECKS=1.
- **Лицензии:** source/license каждой сторонней модели, текстуры и клипа — `assets/README.md`; не переносить чужие game/UI/audio assets вместе с примером. Покупки/установки не поручены.
- **Evidence:** `builds/checks/IP-01/`, `builds/screenshots/IP-01/`; GPU слоты согласовать с MOTION-01, без тяжёлой параллельной нагрузки.
