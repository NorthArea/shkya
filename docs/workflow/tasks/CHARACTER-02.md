- **Владение:** `game/player/character_air_motion.gd` и собственные developer tests — character_air_mechanics; root подключает `game/player/ilyusha.gd` и motion→pose после стабильной QA LOCOMOTION-01/IP-01. Модели/камера/миссия не принадлежат автору helper.
- **Контракт до кода:** принятый helper `begin_step` получает delta/velocity/floor/direction/limit/fresh jump/control gate; `request_air_attack` выбирает допустимое действие, `resolve_contacts` возвращает однократные hit/land/stomp pulses, `snapshot` — phase/action для gait, `cancel` очищает состояние. Ilyusha остаётся единственным владельцем velocity/collision/root; air cancel/reset согласуется с CHARACTER-04.
- **Поведение:** moving launch без долгого idle anticipation, сохранение XZ-импульса и bounded air steering/shortest-arc facing. Второй прыжок только один, по свежему вводу в согласованном окне; ранний/поздний ввод не копится. Natural fall не даёт второго прыжка/air attack. Floor завершается одним landing; движущий ввод может продолжить обычную посадку, stomp имеет своё завершение.
- **Взаимодействия:** jumpkick/stomp используют только действующих drone/breakable/push consumers и свой код/анимацию; новых классов целей/насилия нет. Кнопки прыжка/удара/бега, деньги/награды и маски сохраняют контракты.
- **Отмена/приоритет:** place/enter/hide/reset/fail/input lock очищают pending air action/hit/second credit; пауза/телефон замораживают состояние без накопления ввода. Не допустить двух владельцев reset в CHARACTER-02/04.
- **Независимая QA:** второй/запрещённый третий прыжок, раннее/позднее окно, natural fall, jump+punch, ровно один hit, импульс/отпускание бега, потолок/стена/крыша машины, pause/reset/enter/hide/fail. Реальные Main/player → цели; MOTION/PAD/PUNCH/укрытия/периметр/стелс и затронутые seat/rig проверки.
