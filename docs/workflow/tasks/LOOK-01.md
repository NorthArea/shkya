# LOOK-01 — Персонажи в игре похожи на свои арты

Результат: полицейский, «военком», Илюша, Бабка, продавщица и жители в игре, с игровой камеры, узнаются как на концептах/листах. Поручение владельца 29.10.2026 (ночь): после игры он не видит сходства полицейского и других с артами, хотя три независимые сверки по листам SVG дали «похож». Значит, теряется что-то между SVG и экраном — или сверки мерили не то.

Владелец: root. Зависимости: EXT-01, PEOPLE-01. Часть A — разбор причин, часть B — правки конвейера и арта.

## Гипотезы для проверки (по коду)

- Импорт SVG: `svg/scale=1.0` при холсте 400×600 — текстура 400×600 на персонажа ростом ≈2 м; на 1080p при камере в 6–10 м персонаж занимает 150–250 px — линии `LINE` 1,8 ед. становятся < 1 px и пропадают; у `police_*`/`officer_*` `mipmaps/generate=false` (у ART-01 — true) → мерцание и «каша» на дистанции.
- `CharacterSprite`: `pixel_size`, фильтрация текстуры (linear/nearest), `tint` (у Бабки 1,06/1,02/0,88; у полицейского 1,0), `billboard`, высота холста `height_m` — проверить, что масштаб и пропорции в игре совпадают с листом (замер по кадру).
- Освещение: ночной свет и тёплые фонари перекрашивают заливки (жёлто-бежевое лицо полицейского при лампе становится… — измерить по кадру), `shaded`/`unshaded` спрайта, тени на спрайте.
- Дистанция и ракурс: игрок видит персонажей в 3/4 сверху с камеры-следования; лист — фронтально. Ракурсов только три (спина/лицо/бок) — в 3/4 выбирается ближайший и фигура «плоская».
- Сверки сравнивали лист с концептом по пропорциям, а не кадр из игры с концептом по впечатлению.

## Часть A — разбор

Снять одинаковые кадры: каждый персонаж с игровой камеры (как видит игрок: следование за Илюшей, диалог, подход) и рядом концепт; увеличить 1:1; измерить по кадрам: px на рост, толщина контура в px, цвет лица в игре против SVG, резкость (мипмапы/фильтр), ракурс. Назвать 3–5 главных причин потери сходства с доказательством (число/кадр).

## Часть B — правки

По причинам из A: `svg/scale` 2–3× для всех персонажей (или рендер SVG в PNG нужного размера), мипмапы и фильтр, контур толще там, где он исчезает на дистанции (единый `LINE` для игры, не для листа), `unshaded` или мягкий свет на спрайтах, тёплый `tint` не искажает цвет лица, камера диалога крупнее, высоты `height_m` по росту персонажей; при необходимости — четвёртый ракурс 3/4 для главных персонажей. Проверка: кадры «до/после» рядом с концептом с игровой камеры, независимая сверка по кадрам из игры (не по листу), ART01/QUEST01/DEMO зелёные, FPS ≥ 100.
