# RADIO-01 — две автомобильные радиостанции

Статус — [backlog](../backlog.md); решение — [DECISIONS](../../DECISIONS.md), «Автомобильное радио».

- **Результат:** «Радио Н.»: Cold Funk → Local Forecast - Elevator → Monkeys Spinning Monkeys → Sneaky Snitch по кругу. «Классика»: Beethoven Moonlight I / Paul Pitman и Chopin Op. 9 № 1 / Olga Gurevich без диктора.
- **Контекст:** только реальный водитель внутри машины; остановка допустима. При выходе звук прекращается, индекс и позиция сохраняются; пауза оставляет прежнего Шопена.
- **Новости:** правила RADIO-02; следующая запись ждёт дочитывания передачи. Незавершённый AudioServer playback не перезапускается до доставки finished.
- **Настройка:** собственный шум перед включением/сменой; R и крестовина вправо. Один музыкальный плеер и один плеер настройки.
- **Права:** все четыре записи Kevin MacLeod — CC BY 4.0; классика — public domain. Первичные ссылки/атрибуция — `assets/audio/radio/README.md` и настройки. Ogg stereo48кГц, без клиппинга; темп/динамика сохранены, Local Forecast тише остальных на3,66дБ из-за ограничения пиков.
- **Проверено:** RED4/1→GREEN86/0; два реальных цикла finished, курсор/станции/пауза/входы/выходы. Независимый детерминированный interleaving RED7/1→GREEN13/0: AudioServer end до доставки finished; исправление подтверждено точным исходником Godot. Evidence `builds/checks/RADIO-01/playlist/`.
- **Сборка ассетов:** `tools/prepare_radio_audio.py` содержит SHA всех мастеров. Декодирование/соответствие записям проверены независимо; прослушивание не выполнялось.
- **Резерв:** Ciolkowska — «Около того» (2018, CC BY 4.0), не включён: доступный stream128 и длительность7:33 требуют отдельной художественной пробы.
- **Открыто:** ручное прослушивание темпа и баланса владельцем; текущие дополнительные треки — конкретный кандидат для этой пробы.
