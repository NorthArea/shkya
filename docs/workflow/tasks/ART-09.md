# ART-09 — разнообразие персонажей в рисовке ШКЯ

**Статус:** review 31.10; ограниченная интеграция принята независимым ревью, интегратор root. Общая квалификация и игра владельца открыты.
**Решение:** DECISIONS «Персонажи: разнообразие» (30.10); [полная подборка владельца](../../art/references/ШКЯ/), исходные имена/файлы сохранены без изменений.
**Результат:** различимые типажи полицейских, ОМОНа и гражданских по референсам; узнаваемая рисовка ШКЯ, тонкий контур в игре, лица/пропорции/одежда из канона. Различие читается с обычной игровой камеры.
**Исследование:** лично просмотреть все изображения, сопоставить с CHARACTERS и существующей системой SVG/CharacterSprite; выделить подтверждённые формы лиц/силуэтов/одежды и предложить набор образов. Не ограничиваться перекраской.
**Файлы:** tools/generate_characters.py, новые assets/art/characters SVG и их import, при необходимости узкое presentation API CharacterSprite/Npc; отдельный тест/съёмщик вариантов. Population/Life/Resident/граф принадлежат ARENA-03, изменение их файлов только через интегратора.
**Роль и облик:** внешний вариант не создаёт новых сенсоров/постов/поведения. Варианты полицейских/ОМОНа применяются к существующим ролям через явное представление; размещение дополнительных игровых патрулей требует отдельного дизайна C7. Гражданские варианты интегрируются в население ARENA-03 без изменения его размера.
**Контракты:** C7/C9; персонажи 2D, исходные PNG-концепты не менять, квестовые герои сохраняют каноническую узнаваемость. Файлы подборки не становятся игровыми текстурами; новые SVG — собственная работа с указанным источником.
**Проверка:** генерация детерминированна и не перезаписывает несвязанные облики; front/back/side и штатные кадры анимации доступны; лица и тонкий контур читаются в игре. Существующие sprite/NPC/стелс-оракулы не ослаблять.
**Приёмка:** независимое сравнение с лично просмотренными референсами и CHARACTERS, реальные игровые ракурсы/дистанции, несколько вариантов рядом; лист SVG не заменяет игровой вид. Логи builds/checks/ART-09/, кадры builds/screenshots/ART-09/. Автор не принимает себя.
**Реализовано:** шесть комплектов (90 SVG); appearance до _ready отделён от роли; два существующих поста чередуют пары при новом мире, шесть из 64 жителей получили parka/scarf. Капюшон omon_hood замкнут, проём лица отделён от ткани. Прежние 78 SVG сохранены.
**Адресный тест:** ART09 включён в make test; проверяет реальные посты/сенсоры, шесть гражданских, повторное создание мира и reset наряду с ракурсами/ходьбой. В основном дереве ART09 — 305 checks, 0 failures (`builds/checks/ART-09/main-live-test-fixed.log`); состав сенсоров сверяется по конкретным владельцам, включая заранее созданный выключенный ClosureVan.
**Кадры:** прежняя витрина сохранена; режим того же capture -- --native подготовлен для действующих постов и шести гражданских в двух мирах и после меню, без перестановки NPC. Сохранены 24 кадра 1920×1080: два последовательных мира и третий после меню (`builds/screenshots/ART-09/native/`, лог `native-capture.log`); NPC не переставлялись, планы не менялись.
**Независимое ревью:** шесть типов и исправленный капюшон приняты в проверенной области по витрине и кадрам действующих участников; роли/точный состав сенсоров и тестовые изменения проверены. Прежний безусловный cycle дал один ожидаемый FAIL на сценарии меню (menu-cycle-red.log), затем точные байты исправления восстановлены. Два вида каждого патруля готовы, в одном прохождении виден один полицейский и один росгвардеец; совместное размещение требует дизайна ролей и не объявляется реализованным.
**Интеграционный сбой:** первый make test остановился на STUCK: старый query World|Car принимал пешие старты внутри SnowBank. Подъём воспроизведён до ввода; такие же отказы есть в логах DRIVE-02 от 29.10. Новые разрывы валов изменили выборку и проявили прежний дефект фикстуры. Все пешие queries теперь используют маску Илюши; автомобильный default и допуски сохранены. Две незаконные точки и соседний законный подход/отход выведены из Layout: адресно 5/0, старая маска даёт два ожидаемых FAIL, независимое ревью принято. Первый отказ — integration-failure-polish01_stuck-60.log, причина — stuck-snow-probe.log, регрессия — stuck-start-layout.log и stuck-start-red.log.
**Открыто:** игра владельца и общая квалификация интегрированного дерева; повторный make test (39 наборов) выполняется, FPS ещё NOT_RUN для текущего среза. Git/backlog/DECISIONS и итоговые проверки — root.
