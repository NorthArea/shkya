# ART-09 — разнообразие персонажей в рисовке ШКЯ

**Статус:** in_progress; отдельная чистая сессия, интегратор root.
**Решение:** DECISIONS «Персонажи: разнообразие» (30.10); [полная подборка владельца](../../art/references/ШКЯ/), исходные имена/файлы сохранены без изменений.
**Результат:** различимые типажи полицейских, ОМОНа и гражданских по референсам; узнаваемая рисовка ШКЯ, тонкий контур в игре, лица/пропорции/одежда из канона. Различие читается с обычной игровой камеры.
**Исследование:** лично просмотреть все изображения, сопоставить с CHARACTERS и существующей системой SVG/CharacterSprite; выделить подтверждённые формы лиц/силуэтов/одежды и предложить набор образов. Не ограничиваться перекраской.
**Файлы:** tools/generate_characters.py, новые assets/art/characters SVG и их import, при необходимости узкое presentation API CharacterSprite/Npc; отдельный тест/съёмщик вариантов. Population/Life/Resident/граф принадлежат ARENA-03, изменение их файлов только через интегратора.
**Роль и облик:** внешний вариант не создаёт новых сенсоров/постов/поведения. Варианты полицейских/ОМОНа применяются к существующим ролям через явное представление; размещение дополнительных игровых патрулей требует отдельного дизайна C7. Гражданские варианты интегрируются в население ARENA-03 без изменения его размера.
**Контракты:** C7/C9; персонажи 2D, исходные PNG-концепты не менять, квестовые герои сохраняют каноническую узнаваемость. Файлы подборки не становятся игровыми текстурами; новые SVG — собственная работа с указанным источником.
**Проверка:** генерация детерминированна и не перезаписывает несвязанные облики; front/back/side и штатные кадры анимации доступны; лица и тонкий контур читаются в игре. Существующие sprite/NPC/стелс-оракулы не ослаблять.
**Приёмка:** независимое сравнение с лично просмотренными референсами и CHARACTERS, реальные игровые ракурсы/дистанции, несколько вариантов рядом; лист SVG не заменяет игровой вид. Логи builds/checks/ART-09/, кадры builds/screenshots/ART-09/. Автор не принимает себя.
**Открыто:** набор вариантов и безопасное подключение к ролям, runtime/визуальная приёмка, интеграция с ARENA-03. Git/Makefile/backlog/DECISIONS и итоговые проверки — root.
