# ART-09 — разнообразие персонажей в рисовке ШКЯ

Статус, зависимости и владелец — [backlog](../backlog.md).

- **Основание:** DECISIONS «Персонажи: разнообразие» и уточнение владельца 31.10; [полная подборка](../../art/references/ШКЯ/), CHARACTERS, e01_police_dialog/e03_uniforms. Исходные имена/файлы и PNG сохраняются.
- **Результат:** исходный полицейский без синей нашивки и с выраженными погонами; рядом два различимых полицейских и один омоновец в той же манере. Каждый кандидат показан с исходным при одном масштабе/камере, затем сбоку/сзади/в ходьбе; новая визуальная приёмка предшествует назначению в город.
- **Владение:** `tools/generate_characters.py`, собственные `assets/art/characters/*.svg`/import, узкое presentation API CharacterSprite/Npc, адресный тест/съёмщик. Population/Life/Resident/граф — ARENA-03, изменения через root.
- **Контракты:** C7/C9, 2D и каноническая узнаваемость. Облик не создаёт постов/сенсоров/поведения; дополнительные патрули требуют отдельного дизайна C7. Гражданские варианты не увеличивают население. Файлы подборки не используются как текстуры; источники собственных SVG отражены в реестре ассетов.
- **В основном дереве:** исходные police/guard назначены постам, одобренные гражданские облики сохранены; отклонённые варианты удалены. Кандидаты V3 — молодой полицейский без усов, пожилой с седыми усами и омоновец в зимней шапке с рацией — доступны в штатных ракурсах/позах, в город не назначены. Независимое сравнение с e01/e03 подтвердило манеру и различимость; художественная оценка владельца открыта.
- **Проверка:** генерация детерминирована и сохраняет несвязанные облики; front/back/side/анимации читаются с игровой камеры. Sprite/NPC/стелс-оракулы и whitelist не ослаблять; прежний положительный вердикт отклонённым вариантам не переносится на V3.
- **Evidence:** `builds/checks/ART-09/{restore-originals,v3-static}.log`, `builds/checks/REVIEW-01/art09_test.log`, `art09_test-approved.log`; `builds/screenshots/ART-09/revision3/*_comparison.png`. Адресная проверка текущих назначений пройдена; полный PASS не заявлен.
- **Открыто:** общая квалификация интегрированного дерева, сравнение кандидатов в реальной игре и решение владельца об их назначении. Листы SVG и технические проверки не заменяют приёмку.
