# MISSION-01 — Логика миссии «За хлебом»

Результат: `MissionDirector` полностью реализует FSM раздела 6 канона и правила раздела 5 как чистую логику без сцены; все переходы и запреты проверены тестами. Это владелец состояния для GREY-01, DRIVE-01 и QUEST-01.

Владелец: —. Файлы: `game/mission/mission_director.gd`, `tests/mission_director_test.gd`, строка в `Makefile`. Чужие файлы не трогать.

Контракт: C5 из [README](../README.md#общие-контракты). Можно делать параллельно с GREY-01: зависимостей от мира нет.

Правила:

- `interact(&"babka")`: `NOT_STARTED` → `OFFERED`; в `RETURN_HOME` при `has_bread` → `COMPLETE`, `has_bread = false`, `xp += 50`; иначе — обычная реплика без изменений.
- `accept()`: `OFFERED` → `GO_TO_CAR`; `decline()`: `OFFERED` → `NOT_STARTED`.
- `notify_entered_car()`: `GO_TO_CAR` → `DRIVE_TO_KIOSK`; в других состояниях ничего не делает (повторный вход разрешён).
- `notify_arrived_kiosk()`: `DRIVE_TO_KIOSK` → `BUY_BREAD`.
- `buy_bread()`: только в `BUY_BREAD` и при `money >= 35` → `RETURN_HOME`, `has_bread = true`, `money -= 35`, сигнал `bread_received`. Стартовых денег заведомо хватает.
- `COMPLETE` необратим; `reset()` возвращает `NOT_STARTED`, `has_bread = false`, `xp = 0`, стартовые деньги.
- `babka_marker()`: `"!"` в `NOT_STARTED` и `OFFERED`; `"?"` только в `RETURN_HOME` с `has_bread`; иначе пусто.
- `objective()` и `prompt_for(id)`: заголовок и задача — по кадрам 01–10 (кадр 01: «НОВОСИБИРСК» / «Подойди к Бабке»; кадр 06: «ЗА ХЛЕБОМ» / «Поговори с продавщицей»); подсказки — «E — ПОГОВОРИТЬ», «E — СДАТЬ ЗАДАНИЕ» из раздела 4. Для остальных состояний текст брать с соответствующего кадра; если кадра нет — записать выбранный текст в эту карточку.

Критерии: каждое состояние × каждая команда даёт ожидаемый переход или отказ без изменений; полный проход от `NOT_STARTED` до `COMPLETE`; отказ и повторное принятие; покупка без квеста, повторная покупка, сдача без хлеба и повторная награда запрещены; `?` не появляется до покупки; сигналы приходят ровно один раз.

Проверка: `tests/mission_director_test.gd` в `make test`, лог `builds/checks/mission01/`. Ожидания выводить из канона, не из кода. Независимое ревью до `done`.
