# ART-08 — Второй пост и остатки P3 персонажей

Статус: review (29.10) — ждёт игры владельца.

**Результат.** Второй наблюдатель у киоска получает свой облик — росгвардеец по третьей фигуре e03: берет, серо-синяя форма, бронежилет, без реальных эмблем и надписей; «дружинника» нет (решение владельца 28.10). Прохожие ШКЯ и полицейский закрывают замечания P3 прежних сверок. Приёмка — по методу ART-07 (наложение и кадры из игры).

**Файлы.** `tools/generate_characters.py` (`guard()`, правки `resident_*`/`police_*`), `assets/art/characters/guard_*`, `game/world/patrols.gd`, `assets/README.md`.

**Интерфейсы.** `Officer2.character = "guard"` — это проверяет STEALTH. У `Svg` в генераторе необязательный viewBox: у guard `-24 0 448 600` (фигура шире холста), остальные SVG без изменений.

**Критерии.** Силуэт ≤ 10 %, лицо ≤ 15 % по маскам; росгвардеец не путается с полицейским на 10 м; независимая сверка «похож / в стиле»; последнее слово — владелец после игры.

**Проверка.** ART01 (60 и 120 к/с), RESIDENTS, QUEST01, STEALTH.

**Сделано / открыто.**
- 2b23b20: `guard()` в трёх ракурсах (бордовый берет без кокарды, форма, чёрный бронежилет с подсумками, лицо с брылями, рост как у полицейского), цели по маскам выполнены. P3 прохожих: шуба — лицо-груша с брылями, пацаны — круглые лица с румянцем, берет со спины без «улыбки», фиолетовая — наклон и локти шире, ушанка — широкое лицо и согнутая нога, турист — открытый рот; усы полицейского — щётка.
- Ревьюер: росгвардеец похож на e03, в стиле, P1 нет.
- Открыто: P2 — лица шубы и пацанов на 3 м не различаются; P3 — форма росгвардейца светлее и голубее концепта; игра владельца.
