# QA-01 — Приёмка демо

Результат: независимая проверка всех восьми приёмочных сценариев раздела 8 канона на собранной версии и ручной проход без подсказок разработчика.

Владелец: независимый исполнитель, не автор кода GREY-01, MISSION-01, DRIVE-01, QUEST-01. Файлы: `tests/demo_acceptance.gd`, `tests/playthrough_driver.gd`, эта карточка.

Состав:

- автоматический проход 01→10 настоящим вводом: ходьба к Бабке, принятие, посадка, поездка по `route_drive`, выход, покупка, возврат, сдача; затем повторный запуск из меню и второй проход;
- проверки сценариев 2, 3, 5, 6, 7 на этом проходе и на отклонениях: отказ, покупка без квеста, сдача без хлеба, повторная награда, выход из машины посреди пути, сброс машины;
- сценарий 4: кадры Илюши в каждой из десяти сцен и при входе/выходе из машины;
- сценарий 8: замер FPS из POLISH-01 на выбранной конфигурации;
- ручной проход человеком, не знающим маршрута: время 5–8 минут, где искал дорогу, что было непонятно.

Ожидания выводить из канона и контрактов C1–C6, не из кода и пояснений авторов.

Критерии: все восемь сценариев `PASS` либо открытый дефект с карточкой; ручной проход записан отдельно от автоматического; `NOT_RUN` для недоступных проверок не скрывается.

Проверка: `make test`, логи `builds/checks/qa01/`, кадры `builds/screenshots/qa01/`.
