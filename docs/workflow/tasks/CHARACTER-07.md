# CHARACTER-07 — единый масштаб персонажей и машин

Статус — [backlog](../backlog.md), решение MSG-0156 (заменяет MSG-0142) — [DECISIONS](../../DECISIONS.md).

- **Назначение:** интегрируемый срез для просмотра, для новой выбранной формы Илюши №4; облик — IP-01.
- **Результат:** Илюша имеет видимый рост мужского ориентира РФ из Catalog от подошв до верхней точки в rest pose (прежний рост отменён MSG-0156); стоя и за рулём одинаковый масштаб. Остальные взрослые — относительно подтверждённых данных роста граждан РФ с сохранением разнообразия; машины проверены по реальным габаритам моделей.
- **Владение:** selected_hero_model — новая геометрия/Catalog; selected_hero_body_qa — независимые actual bounds/scale/cabin/суставы; root — интеграция и общий QA. Чужие физику/салон не менять ради прохождения новой модели.
- **MSG-0160/0161:** рост/выбранный облик героя фиксированы; масштаб остального окружения исправлять. Все реальные модельные ряды транспорта сверить с паспортами, включая кузов/бамперы/колёса/оси, collision/парковки/поток/службы/дальний фон; доказательства и unknown различать.
- **Владение транспорта:** vehicle_passport_specs — первичные паспорта и vehicle_dimensions; vehicle_passport_geometry — factories/size-consumers; root — связная посадка/интеграция/независимая QA.
- **Контракт:** canvas height не равен actual height; один источник реального роста героя для стояния и машины. Пропорции нового Илюши — по выбранному №4; сохранить камеры, маршруты, настроенную езду и роли NPC. Масштаб модели не меняется во время посадки.
- **Настоящие потребители:** Ilyusha/CharacterSprite/Catalog/UniformVisual, LadaDriver, троллейбусные облики, Residents, коллизия, сенсоры, укрытия, cabin/руль/двери.
- **Источник:** [NCD-RisC/eLife2016](https://elifesciences.org/articles/13410), [первичная CSV](https://ncdrisc.org/downloads/height/NCD_RisC_eLife_2016_height_age18_countries.csv): оценка взрослого роста российской когорты1996 (не среднее всех современных взрослых); пол/возрастная группа обозначены; усреднение детей со взрослыми не использовать как взрослый эталон. Численные runtime constants только в коде.
- **QA:** CPU world bounds/rest-to-seat scale, совпадение с коллизией, roof/floor/steering/grips; независимая проверка выбранного scale API и затронутые IP/LOCOMOTION/cabin/hide/perimeter. Headless/Dummy; внешний вид и ощущение принимает владелец.
- **Исторические evidence (старый рост/mesh, не приёмка нового):** `builds/checks/MOTION-01/main-scale.log`16/0, `main-cabin.log`13/0, `main-trolley.log`77/0; источники взрослого роста и размеры транспорта — `builds/checks/CHARACTER-07/`. Проверенный основной визуальный срез не включает новые air/NPC механики.
- **Исторические размеры до паспортной правки:** полный прототип2106 с бамперами4.310м против номинальных4.166м; крыша1.463м, антенна отдельно. Прочие машины сохраняют существующие масштабы. Проверка не означает точного совпадения каждого элемента кузова с заводским чертежом.
- **Открыто:** взгляд владельца, GPU/кадровый темп и непрерывная посадка CHARACTER-04; технический PASS не заменяет визуальное принятие.
- **Паспортный QA:** замеры actual production mesh по явным поверхностям кузова (без антенн/зеркал/снега), отдельно bumper span/roof/wheelbase/track; реальные экземпляры и коллизии, no hidden scale, сохранение damage/cache и проходов. Evidence — builds/checks/CHARACTER-07/passport/.
