# CHARACTER-07 — единый масштаб персонажей и машин

Статус — [backlog](../backlog.md), решение MSG-0142 — [DECISIONS](../../DECISIONS.md).

- **Назначение:** интегрируемый срез для просмотра, без изменения утверждённых лиц/пропорций/текстур.
- **Результат:** Илюша имеет точный видимый рост1.50м от подошв до верхней точки в rest pose; стоя и за рулём одинаковый масштаб. Остальные взрослые — относительно подтверждённых данных роста граждан РФ с сохранением разнообразия; машины проверены по реальным габаритам моделей.
- **Владение:** current_gait_audit — аудит и согласованные scale configs; root — интеграция/физическая коллизия/QA; radio_broadcast_clock — отдельная посадочная проба. Производственные изменения только в изолированном feature-tree.
- **Контракт:** canvas height не равен actual height; один источник реального роста героя для стояния и машины. Сохранить пропорции, камеры, маршруты, стилизованный облик, настроенную езду и роли NPC. Масштаб модели не меняется во время посадки.
- **Настоящие потребители:** Ilyusha/CharacterSprite/Catalog/UniformVisual, LadaDriver, троллейбусные облики, Residents, коллизия, сенсоры, укрытия, cabin/руль/двери.
- **Источник:** [NCD-RisC/eLife2016](https://elifesciences.org/articles/13410), [первичная CSV](https://ncdrisc.org/downloads/height/NCD_RisC_eLife_2016_height_age18_countries.csv): оценка взрослого роста российской когорты1996 (не среднее всех современных взрослых); пол/возрастная группа обозначены; усреднение детей со взрослыми не использовать как взрослый эталон. Численные runtime constants только в коде.
- **QA:** CPU world bounds/rest-to-seat scale, совпадение с коллизией, roof/floor/steering/grips; независимая проверка выбранного scale API и затронутые IP/LOCOMOTION/cabin/hide/perimeter. Headless/Dummy; внешний вид и ощущение принимает владелец.
- **Открыто:** источник и распределение взрослого роста, единый provider, actual world bounds автомобилей, seated fit и зависимые regression checks. Технический PASS не означает визуальное принятие.
