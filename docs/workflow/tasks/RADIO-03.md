# RADIO-03 — живые эфиры и выключенный приёмник

Статус — [backlog](../backlog.md), решения — [DECISIONS](../../DECISIONS.md), MSG-0136/0137/0139.

- **Результат:** два независимых эфира живут по времени мира, даже когда Илюша слушает другую станцию, идёт пешком или выключил радио. При подключении слышен текущий трек с текущей позиции; переключение не возвращает к сохранённому месту.
- **Третье положение:** «Радио выключено» — без музыки, настройки и диктора. Оно выключает приёмник, сохраняя ход обоих эфиров, городской звук/машину и отдельную музыку меню/паузы; не становится третьим плейлистом.
- **Состав:** у классики первая часть «Лунной сонаты» и «Полёт валькирий». Существующий плейлист «Радио Н.» сохраняется; MSG-0136 о количестве треков — вопрос о составе, не поручение сократить его.
- **Владение:** radio_broadcast_clock — `game/audio/radio_music.gd`, `radio_timeline.gd`, связанные радио-секции `car_radio.gd`/сценарии; radio_valkyries_asset — разрешённая запись, подготовка и атрибуция; root — согласование интерфейсов/интеграция/QA.
- **Реальные участники:** SoundDirector/CarRadio/RadioMusic, Main/пауза, DemoWorld и вход/выход из машины; часы треков отделены от состояния приёмника. Время игрового мира на паузе не идёт; проигрыватель не определяет ход неслушаемой станции.
- **Новости:** RADIO-02 сохраняется: первая погода после требуемого услышанного музыкального интервала, срочные с duck, обычные в межтрековом окне. OFF/классика не пропускают диктора; события остаются правдивыми, очередь и возобновление не дублируют новости.
- **Критерии:** слушать Live, переключить на классику на время нескольких треков и вернуться на текущую позицию Live; повторить через OFF и выход из машины. Ноль звуков радио в OFF, прежние управление/субтитры/приоритеты UI сохранены.
- **QA:** независимые timeline/boundary/interleaving сценарии, реальные RadioMusic/CarRadio в Main, радио/аудио/STORY/геймпад/пауза. Права подтверждаются для конкретной фонограммы, не только произведения; атрибуция и включение Ogg проверяются отдельно.
- **Evidence:** `builds/checks/RADIO-03/`. Исполнение только headless/Dummy; слышимый баланс, качество записи и ручное впечатление NOT_RUN до отдельного разрешённого просмотра. Старые RADIO-01/02 PASS не принимают новые часы/OFF.
