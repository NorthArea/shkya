# DRIVER-01

Статус — в [backlog](../backlog.md).

Результат: явно включаемый водительский контроллер race/pursue/evade в настоящем TrafficCar для будущих миссий.

Область: driver_ai_hitrun — DriverAI/DriverRoute и адаптер; независимый QA — сценарии до чтения реализации; root — контракт, композиция, Godot/Git.

Источники: 3UR c84f9ff, src/game/ai/vehicle/chaseai.cpp, vehicleai.cpp, waypointai.cpp; локальный source /private/tmp/shkya-3ur-source/, код не переносится.

Контракт: planner не телепортирует/не пишет скорость, выдаёт ограниченные команды потребителю. C8 обычного трафика сохраняется; race имеет упорядоченные checkpoint, pursue ограниченную last-seen память, evade достижимую дорожную цель.

Топология: существующие Layout дороги и обе легальные полосы, соединения на перекрёстках; блокированное ребро исключается при планировании, доступный объезд выбирается. Если безопасного пути нет — конечное ожидание/reverse, без выдуманного проезда через стены.

Критерии: прогноз цели, торможение перед кривизной/препятствием на снегу, пешеходы и трафик, движение без overlap/скачков, честные скорость/ускорение/видимость. После удара — общая VEHICLE физика, после режима — непрерывное возвращение на полосу.

Проверка: developer + независимые real TrafficCar route/LOS/closure/recovery сценарии, TRAFFIC/DRIVE и C9. Новые миссии не входят; оценка «лучше эталона» требует наблюдения и ручной пробы.
