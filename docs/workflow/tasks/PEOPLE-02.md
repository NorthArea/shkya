# PEOPLE-02 — Прохожие из артов ШКЯ

Результат: жители города Н. — узнаваемые персонажи роликов ШКЯ (Ева Морозова), а не придуманные силуэты. Поручение владельца 29.10.2026 (ночь): «добавь прохожих обязательно из артов ШКЯ, найди в интернете».

Владелец: root. Зависимости: PEOPLE-01 (поведение и маршруты остаются), LOOK-01 (конвейер показа). Часть A — исследование референсов, часть B — арт, часть C — замена силуэтов в `residents.gd`.

## Границы

- Референсы — только описания и ссылки: кадры чужих роликов и чужие изображения в репозиторий не кладутся (раздел 6 референсов, решение владельца). Рабочие копии кадров — только во временном каталоге сессии.
- Рисуем сами в генераторе, в манере ART-01 (тонкий контур, пропорции лиц по роликам). Не копировать покадрово; узнаваемость — через силуэт, причёску, одежду, лицо.
- Илюшу и Бабку-квестодательницу не дублировать среди прохожих. Запреты канона и расширения в силе.

## Часть A — референсы

Найти в интернете материалы по персонажам ШКЯ: ролики Евы Морозовой (V01 «Илюша, пристегнись», V02 «Цирк», другие серии), стоп-кадры, описания, фан-арт (только как подсказка, не источник). Составить `docs/art/shkya_characters.md`: для каждого повторяющегося персонажа ролика — имя или роль, где встречается (ссылка, тайминг), словесный паспорт (силуэт, голова, нос, глаза, причёска/головной убор, одежда, цвета, характерная поза), пригодность на роль прохожего. Выбрать 4–6 персонажей на замену нынешним силуэтам (бабка с сумками, мужик, женщина с санками, пацан) с обоснованием.

## Часть B — арт

По паспортам из A: три ракурса на персонажа в `tools/generate_characters.py` (имена `resident_<slug>`), зимняя адаптация одежды без потери узнаваемости (как у Илюши: лицо и пропорции каноничны, шорты не копировать). Лист и кадры с игровой камеры (после LOOK-01 — по новому конвейеру). Независимая сверка «узнаётся как персонаж ШКЯ / нет» по кадрам из игры.

## Часть C — замена

`residents.gd` `SILHOUETTES` → новые имена; маршруты и поведение PEOPLE-01 без изменений; RESIDENTS зелёный.

## Часть A — результат (29.10, ночь)

Каталог `docs/art/shkya_characters.md`: 14 персонажей и групп с паспортами по раскадровкам YouTube (Chrome не был подключён; кадры 232×180 — силуэт, одежда, убор и цвета надёжны, мелкие черты лица приблизительны; перед артом открыть таймкоды в плеере). Подтверждено текстом: Илюша, бабка, дед «с котомкой», мистер Кутёж, офисные толстяки, «бабки со двора». Замены (решение интегратора 29.10, владелец может поменять): бабка в бордовой шубе с пакетами и голубой «чалмой» (вместо бабки с сумками), бабка в розовом с голубым беретом (вторая бабка; кофту — на пальто), мужик в ушанке из «Моложе я не стал.» (единственный зимний 2D-персонаж, три ракурса), пацан в вязаной шапке (2–3 палитры), дед-турист с рюкзаком (второй мужик), бабка в фиолетовом пальто с рыжим тюрбаном (вместо женщины с санками — молодой женщины в зимней одежде в 2D ШКЯ нет, санок нет). Не брать «илюшеподобных» парней; дед Илюши — в резерв. Стоп-кадры — только в scratchpad сессии (`shkya_refs/`), в репозитории — ссылки и таймкоды.

## Части B и C — сделано 29.10 (ночь), сверка по кадрам из игры

Шесть прохожих нарисованы по раскадровкам роликов (`resident_shuba/beret/violet/ushanka/tourist/kid(+kid2)`, 21 SVG), XOR силуэта 8–15 %; подставлены в `RESIDENT_LOOKS` и `SILHOUETTES` (1e5d524), RESIDENTS 383/0. Независимая сверка по кадрам из игры (3/6 м, ряды) против кадров ШКЯ: **все шесть — похож, в стиле**, с Илюшей, Бабкой и между собой не путаются; P1 нет. P2: мужик в ушанке — вариант для ходьбы с опущенными руками (поза с сигаретой — курящему у подъезда) и единая поза «smoke» во всех ракурсах — ART-07 проход 2. P3: лица-прямоугольники у шубы и пацанов, затылок берета читается «лицом», фиолетовая без наклона, у ушанки прямые ноги и узкое лицо, у туриста закрытый рот. Облик — на согласование с правообладателем ШКЯ (владелец).
