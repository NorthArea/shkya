# EXT-01 — Расширение «Ничего необычного»: бусификация как препятствие

Результат: та же миссия «За хлебом», но на пути к киоску и обратно — препятствие по `docs/extension/`: микроавтобус ГСУМ «БЕСПЛАТНЫЙ ПРОЕЗД», полицейский у киоска, «военком» у автобуса, минимальный стелс и чекпоинт. Игра проходима без знания слова «бусификация»; политический смысл — вторым слоем. Все прежние проверки остаются зелёными.

Канон расширения: `docs/extension/` (без правок), референсы `docs/art/concepts/extension/`. Приоритет: `MISSION_EXTENSION.md` (этапы 1–10) → `STEALTH_DESIGN.md` → `GODOT_IMPLEMENTATION.md` → `DIALOGUES_AND_JOKES.md` (пул, 5–7 реплик) → `ACCEPTANCE_TESTS.md`. Решение владельца 28.10.2026.

Контракт: C7 в `docs/workflow/README.md`. Точки — `layout.gd` (C1): `VAN_PARK`, `VAN_PATH`, `ACCOUNT_OFFICER`, `OFFICER_POST`, `OFFICER_POST_AFTER`, `KIOSK_PAVILION`, `KIOSK_BINS`, `STEALTH_CHECKPOINT`.

Границы (README расширения): играем только за Илюшей; дружинника нет; без насилия, оружия, борьбы и сцен задержания; автобус без физики трафика — по маршруту и постановочно; хлеб только в инвентаре; «мобилизация»/«бусификация» не произносятся; реальных эмблем нет.

Владелец: root (интегратор). Зависимости: POLISH-02. Три части параллельно, непересекающиеся файлы.
