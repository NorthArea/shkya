# BUILD-02 — предварительная macOS-сборка

Статус и зависимости — [backlog](../backlog.md).

- **Результат:** автономная universal `.app` и ZIP в `builds/macos/`; запуск на целевом Mac без редактора.
- **Файлы:** `export_presets.cfg`, настройка ASTC в `project.godot`; локальные официальные шаблоны вне Git.
- **Сделано:** .app экспортирован; ad-hoc подпись, ZIP CRC, восстановление и побайтовое соответствие исходному bundle проверены. ZIP передан владельцу.
- **Проверено:** native ARM64 startup, packed-assets13/0 вне проекта, 64 жителя/динамические SVG/шрифт/звук, подпись и восстановление ZIP. Проверка содержимого PCK исполняется тем же editor engine; native startup проверен отдельно.
- **Граница:** предварительная версия; текущая пешая динамика не принята владельцем, новая реализация включена в этот контрольный ZIP; художественный переход IP-01 выполняется следующим срезом. Нотариализация не выполнялась.
- **Проверки:** `builds/checks/BUILD-02/`; текущий ZIP `builds/macos/ШКЯ Ничего необычного-preview.zip`.
