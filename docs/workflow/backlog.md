Канон — [DEMO](../DEMO.md), кадры — [art](../art/README.md), процесс и общие контракты C1–C6 — [README](README.md). Единственный живой статус задач находится здесь. Этапы раздела 8 канона разбиты на задачи так, чтобы независимые части шли параллельно; сроки канона — оценки трудозатрат, не обещание.

## План

```text
BOOT-01 ─┬─ GREY-01 (мир, ходьба, камера, меню) ─┬─ DRIVE-01 (Лада) ─┐
         │                                       ├─ QUEST-01 (диалоги, HUD) ─┴─ POLISH-01 ── QA-01
         ├─ MISSION-01 (FSM миссии) ─────────────┘                                  ▲
         ├─ ART-01 (персонажи ШКЯ) ── встраивание после GREY-01 ────────────────────┤
         └─ ART-02 (зимний город, свет, снег) ── встраивание после GREY-01 ─────────┘
```

Критический путь: GREY-01 → DRIVE-01 → QUEST-01 → POLISH-01 → QA-01. Сразу параллельно можно брать GREY-01, MISSION-01, ART-01 и ART-02.
