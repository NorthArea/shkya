# ШКЯ: Новосибирск

Трёхмерная аркада от третьего лица на Godot: двумерные персонажи ШКЯ в зимнем трёхмерном Новосибирске, управление в духе *The Simpsons: Hit & Run*. Демо — один квест «За хлебом» на 5–8 минут: Бабка просит Илюшу купить хлеб, Илюша едет на белой «Ладе» к киоску и возвращается. Единственный канон — [docs/DEMO.md](docs/DEMO.md).

Сейчас в репозитории только каркас: канон, концепт-кадры, очередь задач и запускаемая заглушка. Миссия ещё не реализована. Состояние работ — в [очереди](docs/workflow/backlog.md).

## Запуск

Откройте `project.godot` в Godot 4.7.2 и нажмите F5, или из корня проекта:

```sh
make run
```

Движок ищется так: `GODOT_BIN`, затем `tools/local/Godot.app` (вне Git; на этой машине — ссылка на движок last-signal), затем `godot`/`godot4` в `PATH`, затем `/Applications/Godot.app`. Launcher перед запуском готовит импорты ресурсов.

## Управление (по канону)

| Действие | Клавиши |
|---|---|
| Ходьба / руление | WASD |
| Камера пешком | Мышь |
| Взаимодействие, вход и выход из машины | E |
| Ручник | Space |
| Пауза, перезапуск, сброс автомобиля | Esc |

## Проверки и сборка

```sh
make test   # smoke-проверка каркаса
make pack   # builds/ShkyaNovosibirsk.pck
```

Логи проверок — `builds/checks/`, кадры — `builds/screenshots/`; `builds/` не входит в Git.
