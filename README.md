# ШКЯ: Ничего необычного

Трёхмерная аркада от третьего лица на Godot 4.7.2: двумерные персонажи ШКЯ в зимнем трёхмерном городе Н. (прототип — Новосибирск), управление в духе *The Simpsons: Hit & Run*. Демо — один квест «За хлебом»: Бабка просит Илюшу купить батон; Илюша собирает монеты, едет на белой «Ладе» к киоску мимо патрулей и возвращается. Канон и порядок его приоритета — [docs/README.md](docs/README.md), состояние работ — [backlog](docs/workflow/backlog.md).

## Запуск

Откройте `project.godot` в Godot 4.7.2 и нажмите F5, или из корня проекта:

```sh
make run
```

`make run` открывает игру на весь экран. Картинка подстраивается под пропорции монитора без полос; в «НАСТРОЙКАХ» меню и паузы можно выбрать разрешение. Выбор сохраняется между запусками. Для оконного запуска: `./tools/run.command --windowed`.

Движок ищется так: `GODOT_BIN`, затем `tools/local/Godot.app` (вне Git), затем `godot`/`godot4` в `PATH`, затем `/Applications/Godot.app`. Перед запуском launcher готовит импорты ресурсов.

## Управление

WASD — ходьба и руль, мышь — камера, E — говорить, сесть и выйти, Space — прыжок (в машине — ручник), F / ЛКМ — удар, Esc — пауза. Геймпад: стики — ходьба и камера, A — прыжок, X — действие, B — удар (в машине — ручник), RT — газ. Источник — список `CONTROLS` в `game/ui/dialog_panel.gd` (его же показывает меню), раскладка — `game/input_setup.gd`.

## Проверки

```sh
make test     # безоконные проверки; графические наборы явно пропускаются
make capture  # требует GPU; видимый запуск — только по отдельному разрешению
make fps      # замер FPS на маршруте машины
```

Логи проверок — `builds/checks/`, кадры — `builds/screenshots/`; `builds/` не входит в Git.

Частный концепт для проверки игрового цикла и показа правообладателям ШКЯ; ограничения — раздел 9 [DEMO](docs/DEMO.md).
