# Исходные ресурсы Гомера

Папка для локальных игровых данных: `art/chars/`.

Для проверки переноса нужны исходные файлы:

- `homer_m.p3d` — модель, материалы и риг;
- `homer_a.p3d` — анимационные данные;
- `homer.cho` — описание анимационных состояний;
- `global.p3d` — общие ресурсы персонажей.

Загрузчик в репозитории Svxy/The-Simpsons-Hit-and-Run ссылается на эти пути,
но самих файлов в проверенном Git-дереве нет. Создание папки их не создаёт.

Игровые данные не входят в Git. До их получения и проверки происхождения
перенос Гомера выполнить нельзя. Открытая лицензия на оригинальные ассеты
Hit & Run в указанном репозитории не заявлена.
